# Shellune 0.4.20

- 本地终端、SSH、RDP 和 VNC 统一提供可恢复的专注视图（`Alt+Shift+F` / `⌥⇧F`），隐藏非必要顶栏、窗格头与工具控件，同时保留认证、证书、失败、重连与关闭确认，并修复 RDP/VNC 焦点回收与 Esc 逐层退出边界。
- RDP/VNC 浮动工具栏支持持续远端操作后自动退场，隐藏或收起后完全移除命中区不再遮挡远端点击，可通过顶部中央指针接近或 `Alt+Shift+T` 无副作用恢复；窗口缩放与全屏切换保持缩放语义并同步更新平移边界。
- 终端搜索持焦时全面隔离编辑、导航按键与图片粘贴，内联展示 IME 预编辑与光标，升级大小写/正则开关为清晰的状态胶囊控件，并在备用屏幕下正确门控菜单与粘贴。
- 统一会话断开、重连与失败的单处反馈层级，RDP/VNC 手动重连期间保留最后画面并阻断误输入，且桌面与 SSH 错误详情全路径脱敏。
- 首页新增独立于主机搜索的分组定位入口与虚拟化分组树（数百个分组下有界绘制与 O(1) 焦点节点、键盘自动滚动与状态保持），支持按协议（SSH / RDP / VNC / 串口）筛选与全协议在线状态过滤，并统一多协议连接表单比例、可搜索分组选择器与校验自动聚焦。
