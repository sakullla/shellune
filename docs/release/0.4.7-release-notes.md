# Shellune 0.4.7

**Shellune** — 连接远程，也专注本地。
A modern terminal for local shells, SSH, and SFTP.

这一版把终端复制粘贴还原为通用快捷键，修复远程桌面地址端口重复与 RDP 签名协商问题，为 SSH、本地终端加上有界缓冲，并打磨了一批主机列表、标签与传输的细节。

## 终端

- **通用复制 / 粘贴**：默认改为 `Ctrl+C` / `Ctrl+V`（macOS 为 `⌘C` / `⌘V`），与其它应用一致。有选中内容时 `Ctrl+C` 复制并取消高亮；没有选中内容时仍作为中断信号送给程序；剪贴板为空时 `Ctrl+V` 原样送入。仍可在 设置 → 快捷键 中改绑或解除绑定。
- **有界输出与输入**：SSH 直连、跳板链与本地 PTY 的输出改为有界积压并施加背压，不丢数据；本地写入移到后台线程，输入超出预算时整次拒绝并明确提示。长时间刷屏时命令块预览、搜索重算都有上限。详见 `docs/release/2026-11-16-ssh-terminal-hardening.md`。

## 连接

- **远程桌面地址**：RDP / VNC 表单里输入 `主机:端口` 会拆分为地址和端口，不再保存成 `主机:3389:3389`；两处端口不一致时在地址栏提示；端口留空时使用协议自己的默认端口（此前会落到 22）。
- **RDP**：在收到服务器能力后再协商加盐 MAC，修复部分服务器上的签名错误。详见 `docs/release/2026-11-16-protocol-hardening.md`。

## 界面细节

- 主机头像取"首字母 + 编号末位"（`stage-01` / `stage-02` 显示为 `S1` / `S2`），同类主机一眼区分。
- 本机 Shell 卡片名称不再被"默认"标签挤压截断；标签页的"已断开 / 未开始"等状态完整显示。
- 断线提示条内直接提供"重连"（或"关闭"）按钮。
- 传输进度显示为 `7.8 MB / 18 MB`，"取消"与状态同行。
- 分组视图的分组标题改为整行分隔条，点击整行即可折叠；桌面与串口记录与 SSH 主机对齐，计数一致。
- 空结果、设置导航焦点环与已删除记录的会话名称等边界状态更清楚。
