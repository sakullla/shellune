# Shellune 0.4.18

- 改善拖动远程 Windows 窗口和调整边框大小时的响应。RDP 支持服务器发送的多色深光标和高分辨率光标；在 macOS 上，远端光标通过 AppKit 跟随鼠标移动。
- 减少远程画面的重复复制、纹理上传和内存占用，改进 RDP 位图解码。RDP 在窗口、全屏和显示器切换时一并协商分辨率与显示缩放；支持动态分辨率的单屏 VNC 服务端也可跟随窗口调整大小。
- 修复 RDP 点击、双击以及复制截图后会话意外断开的问题。RDP 按需传输 Windows 位图，VNC 改进了 UTF-8 剪贴板协商和大文本处理。
- RDP、VNC 在需要凭据时显示登录表单。可按主机和端口记住桌面证书，证书变更时会再次提示。macOS 远程画面获得焦点时可接收系统允许转发的快捷键。
- 任务中心的叠层按钮只在主机主页显示。
