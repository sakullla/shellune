# Shellune 0.4.1

**Shellune** — 连接远程，也专注本地。
A modern terminal for local shells, SSH, and SFTP.

这一版配色改为与 logo 一致，重新打磨了主机列表、设置页和终端头部；新增批量任务、层级分组和可配置的连接保活策略。

## 界面与配色

- **配色取自 logo**：主色改为 logo 的长春花蓝；深色是带靛调的石墨，浅色是冷调纸灰，页面与卡片的层次更清楚。空状态徽记用 logo 同款的蓝到淡紫渐变，终端光标也跟随主色。
- **主机列表**改为一行一台的轻量列表：真正的复选框、每行末尾一个"连接"按钮，转发/编辑/删除弱化为图标。
- **最近连接**显示为"3 小时前"这类相对时间，鼠标悬停可看精确时间。
- **本机 Shell** 压成一行高的启动卡片，主页把更多空间留给服务器列表；窗口较矮时自动隐藏副标题。
- **设置页**改为两级导航（分类 + 子项），分类是轻量的文字导航；快捷键有独立的可搜索页面。修复分类标签错位和无标题设置行多出一行空白的问题。
- **终端头部**合并为一个连续头部；第二行开头标出会话类型（本地 / SSH）和目标（远程地址或本地 Shell 程序路径）。单个待连接窗格不再显示多余的窗格标记。
- 新建主机表单的输入框改为显示示例值（如 `prod-web`、`10.0.0.12 / example.com`）。

## 更快地连接

- **双击主机行**即可连接。
- 在主机搜索框输入关键词后**按回车**，直接连接列表中的第一台；搜索框为空时回车不会连接。

## 主机管理

- **层级分组**：分组可嵌套（如 `生产/Web`），可新建、重命名、删除（删除时主机移到指定分组，不会被删掉），兼容旧版单层分组。
- 分组列顶部是"全部主机"；只有含子分组的节点才显示展开箭头。
- 主机列表虚拟化，数千台主机也只绘制可见行；支持按状态（当前已连接 / 曾经连接过 / 从未连接）筛选，筛选不会发起任何网络请求。
- 批量选择跨搜索和筛选保持，可一次移动到分组。

## 批量任务

- 对选中的主机或当前筛选结果运行多步远程命令：先预览目标与步骤，运行中可暂停、取消，结束后可重试失败的主机。

## 连接

- **保活与超时可配置**：全局默认值可在设置中修改，单台主机可覆盖；设置会用于真实连接。

## 文件与传输

- 文件管理、传输和端口转发的体验更连贯，传输状态显示实测进度。

## macOS

- 关闭窗口时隐藏而不退出，再次打开会恢复原窗口；终端使用登录 Shell 环境，UTF-8 locale 缺失时给出可见的回退提示。

## 下载

- Windows x86_64：便携 ZIP 和 NSIS 安装包。
- macOS Apple Silicon：DMG 安装镜像，使用项目固定证书签名，未经过 Apple 公证。
- Linux x86_64：deb 安装包（amd64）。

Windows 和 Linux 构建未签名。发布附件由各平台 CI 构建，并附 SHA256SUMS。
