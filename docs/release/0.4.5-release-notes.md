# Shellune 0.4.5

这一版修复终端满屏后的滚动与输入问题。

## 修复

- 触控板滚到终端底部后，同一次手势的尾部回弹不再把命令输入行顶回历史记录；重新开始向上滚动仍可查看历史。
- 输入文字、按下终端按键、粘贴或开始中文输入时，自动显示当前命令行，避免在看不到输入内容的位置继续操作。
- 终端协议回复不会打断历史记录浏览。
- 修复制表符补齐的多列输出错位，例如 macOS 的 `ls -C`；小幅滚动按实际累计距离移动。

## 下载

- Windows x86_64：便携 ZIP 和 NSIS 安装包。
- macOS Apple Silicon：DMG 安装镜像，使用项目固定证书签名，未经过 Apple 公证。
- Linux x86_64：deb 安装包（amd64）。
