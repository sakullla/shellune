# Shellune 0.4.13

## 界面与终端配色升级

- 采用现代冷静石墨蓝配色体系：浅色模式改为清透微冷中性底（画布 `#f7f8fa`、面板 `#f0f2f5`、浮层 `#ffffff`）配沉稳石墨文字与冷静蓝强调色（`#2359c8`），消除此前偏黄发灰的暗浊感与刺眼紫调主按钮；深色模式改为低眩光深岩灰分层（`#16181d` / `#1c1f26` / `#232730` / `#292d36`）配柔和天空蓝（`#82b0ff`）。
- 同步更新深色与浅色终端默认背景、前景、光标、选区及 ANSI 16 色（深色 `#16181d` 岩灰软色板、浅色 `#f6f8fa` 清透微灰白软色板），全部 19 个槽位通过可读对比度守卫且不覆盖程序指定的 OSC 与真彩色。

## 弹窗入场防闪屏优化

- 将弹窗遮罩不透明度按深浅主题分层调优（浅色降至 `26%`、深色降至 `48%`），并增加遮罩柔和淡入过渡，消除浅色模式下打开「新建主机」等弹窗时整屏瞬间骤黑的观感。
- 弹窗落定入场不再从完全透明（`0%`）猛然闪白，改为从 `65%` 柔和渐显并轻微落位，彻底解决打开弹窗时的频闪刺眼问题。
