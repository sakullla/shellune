# Shellune 0.4.2

**Shellune** — 连接远程，也专注本地。
A modern terminal for local shells, SSH, and SFTP.

这一版让终端页更安静：正在运行的会话不再在标签下方多占一行。

## 终端

- **头部合并为一行**：已连接、没有需要提示的会话，其目标（远程地址或本地 Shell 路径）以及分屏、终端/文件切换、更多菜单都移到标签行右侧，终端多出一行空间；关闭会话使用标签上的关闭按钮。
- 连接中、已断开、可重新连接、未保存的快速连接、X11 转发，或窗口较窄时，第二行会自动出现，显示状态与对应操作。

## 修复

- 修复 Linux、macOS 上开启截图功能时无法通过代码检查的问题。

## 下载

- Windows x86_64：便携 ZIP 和 NSIS 安装包。
- macOS Apple Silicon：DMG 安装镜像，使用项目固定证书签名，未经过 Apple 公证。
- Linux x86_64：deb 安装包（amd64）。
