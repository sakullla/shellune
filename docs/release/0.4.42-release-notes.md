# Shellune 0.4.42

- 工作区与导航体验升级：统一侧栏折叠状态与持久化（工具栏、快捷键与命令面板一致），折叠态支持键盘访问分组；主机列表选中或搜索命中时不再遮挡分组标签、最近连接时间与在线状态；专注模式新增低干扰悬停退出入口（且在远程桌面会话中与工具栏错位不重叠）；界面字号循环自动持久化，快捷键提示统一跟随当前键位配置。
- 命令面板与标签分屏优化：命令面板支持直接输入 `user@host[:port]`、`ssh://` 与 IPv6 端口快速直连，引入候选缓存与防悬停抢焦点提升大主机库响应；分屏窗格头与待连接卡片明确显示主机/Shell 身份，支持任意嵌套层级分割线键盘聚焦与右/中键同步焦点；全部标签弹窗支持搜索、外部点击关闭、快捷键操作与关闭待连接标签，批量关闭按序确认全部忙碌会话。
- 表单、反馈与设置细节完善：Sync、Backup、Security、Settings 多字段表单补齐 Tab 焦点环、回车提交与无效态红框；密码框展开明文后支持复制；多行编辑控件补齐焦点光晕、滚动条、右键菜单与 `Shift+Tab` 脱出；主机编辑弹窗的密钥/凭据选择器限高可搜索、分组下拉防裁切、未保存退出前二次确认；修复备份导出密码库校验与文案、Sync 冲突已选态、窄幅 Banner 图标区分、Toast 悬停间隙与 `Escape` 关闭，设置侧栏点击子项精确定位到对应区块。
- SFTP、端口转发与批量执行效率提升：文件列表改为单击选中、双击/回车进入文件夹，支持 `Ctrl+F` 过滤、隐藏文件开关、多选批量拖拽、文件夹递归传输、右键菜单键盘导航及停靠文件栏拖拽调宽；传输增加「全部保留/全部替换」与「全部取消/重试全部失败」。端口转发支持自定义标签、搜索筛选、「保存并启动」、列表级报错及按主机批量启停/掉线一键重启。批量执行改用虚拟列表与搜索（解除数量截断），新增确定进度条、可展开输出区、取消中防连点、待信任筛选与从代码片段插入步骤。
- 代码片段、远程桌面与串口补齐：代码片段支持多行编辑、列表滚动跟随、一键复制、快捷键与中文按字符截断修复；RDP/VNC 折叠工具栏保留顶部居中恢复把手，新增特殊键菜单（`Ctrl+Alt+Del` / `Win` / `PrintScreen`）、快捷重连与截图复制到剪贴板、连接中取消、断线压暗重连卡片及证书变更红色警示；串口新增不断标签「断开/重连端口」与 `Send Break`、错误分级可关闭与全量本地化、换行模式持久化及离线点击端口快切重连。
