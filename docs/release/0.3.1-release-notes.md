# Shellune 0.3.1

**Shellune** — 连接远程，也专注本地。
A modern terminal for local shells, SSH, and SFTP.

这一版修复弹窗里右键闪退，并重做了终端的绘制与配色。

## 修复

- **右键闪退**：在弹窗、命令面板或菜单里的输入框上右键会让程序退出（例如新建主机的地址框），现在会正常弹出剪切、复制、粘贴菜单。
- 程序隐藏光标（`ESC[?25l`）时不再画出一条竖线。

## 终端

- **对齐**：每个字符按列定位，中文、图标等其他字体里的字形不会把后面的内容挤歪。
- **制表符与方块字符**由终端直接绘制：边框线无缝衔接，横线不再像虚线；圆角框、粗线框、双线框都正确相接；进度条和方块 Logo 没有缝隙。
- **可读性**：文字与背景过于接近时自动调到可读，浅色终端里为深色终端设计的灰字不再看不见；dim、斜体、删除线现在都会显示。
- **终端配色**：设置页新增"终端配色"（跟随应用 / 深色 / 浅色），会被记住。
- **光标**：块状光标为实心，光标下的字反色显示；终端失去焦点时显示为空心框。

## 界面

- **新建菜单（+ ▾）**：从按钮下方弹出，分"本机"和"服务器"两组，图标按含义区分，默认 Shell 打勾。"自定义路径"改为"打开程序"弹窗。
- **会话栏**：类型改为图标；"已连接"不再重复显示，只在连接中、失败或断开时显示状态；关闭会话改为图标按钮。
- **终端状态栏**：命令块视图改为可开关的图标按钮。

## 下载

- Windows x86_64：便携 ZIP 和 NSIS 安装包。
- macOS Apple Silicon：DMG 安装镜像，使用项目固定证书签名，未经过 Apple 公证。
- Linux x86_64：deb 安装包（amd64）。
