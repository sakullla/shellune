# Shellune 0.4.29

- 修复首页在没有打开终端时（启动后或关闭最后一个标签后）点击主机的“删除”没有反应的问题；同时恢复这种情况下的 Esc、列表键盘操作和批量删除。
- 文件列表只构建屏幕上可见的行，大目录上下滚动不再卡顿。
- 重做“移动主机”：只有一个搜索框和一份可选列表（不属于任何分组、各个分组及其主机数、新建分组），点一下即选中，按钮写明结果，例如“移动到 hk”。删除分组时选择去向也用同一个列表。选择栏精简为“已选 N 台 · 全选 · 清空”和右侧的移动、批量任务、删除。
- 终端配色在 OKLCH 中重新设计：6 种颜色亮度一致，亮色是同一色相明显亮一级而不是发白；深色背景下每种颜色对比度都在 7:1 以上，浅色终端背景与界面底色一致。
- 深色主题底色加深一级，侧边栏与列表层次更清楚；主机头像改为亮度统一、色相均匀分布的颜色，更容易区分。
