# Shellune 0.4.14

## 远程桌面输入

- 修复鼠标在列表顶部向下滚动却没有反应的问题。远程桌面正确区分滚动方向，触控板的短距离滑动可以累积，横向滚动会传给支持它的远端。
- RDP 会先把指针定位到要滚动的控件。VNC 重连期间保留最后一帧，暂停输入，避免掉线前的操作落到新会话。
- 远端提供可见的光标图像时，本机按其形状和热点绘制。仅把指针画在桌面里、尚未发送形状或请求隐藏指针的服务端，会有本机十字光标辅助定位。

## 画面更新

- VNC 支持 ZRLE 压缩，并保留 Hextile 和原始像素兼容。模拟 8 秒往返延迟、每方向 64 kbit/s 的链路上，同一张 480 × 320 图像显示 90% 的时间从 44.55 秒降到 35.55 秒。两种编码还原的最终像素一致。
- 4K 桌面上相距较远的局部更新可以分别传给界面，只重建受影响的纹理。修复了 RDP 位图长度、行填充和 15/16 位色的读取。

测试机上的 TigerVNC 和 GTK 文本列表验证了完整滚动路径。直连和上述弱网条件下，窗口向下滚动后，远端列表偏移均从 0 增至 43.61 像素，反向滚动后回到 0，客户端也收到了对应的画面。
