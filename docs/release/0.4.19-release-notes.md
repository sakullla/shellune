# Shellune 0.4.19

- 本地终端、SSH、RDP、VNC 和串口使用统一的加载过渡。连接超过 1.5 秒才显示加载卡片，快速连接直接进入会话。密码、证书和失败提示即时显示。
- 缩短 RDP 建立连接到首屏的等待时间。双方支持时跳过额外的通道加入往返，并合并发送桌面激活消息。
- Windows 登录后若启动画面仍为全黑，客户端可向支持重绘的服务端补发一次刷新请求。已开始绘制桌面内容时会取消这次请求。
- VNC 首屏可随数据到达逐步显示。Raw 和 Hextile 更早交付已经完整的扫描行或图块，ZRLE 在收到完整的原始或调色板图块后即可绘制。
- 首次自动同步本机剪贴板移至远程画面绘制之后，避免大截图拖慢首屏。macOS 应用包增加本地网络权限用途说明，本地开发版使用独立的应用标识。
