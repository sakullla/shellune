# Shellune 0.4.11

## 护眼配色与视觉层次

- 重构深色与浅色两套 UI 色板：深色模式采用低眩光柔和炭灰阶与柔和暖白文字，浅色模式采用温和暖纸白底与柔和石墨灰文字，拉开画布、面板、浮层与对话框之间的明度层次，消除纯黑/纯白高眩光视疲劳。
- 重构深色与浅色终端默认背景、前景、光标、选区与 ANSI 16 色，去除高饱和荧光刺眼感并满足全部可读对比度与亮暗层级守卫，同时保留程序通过 OSC 与真彩色主动指定的颜色。

## 核心页面交互与效率

- **首页与新建/编辑主机**：保持工具条「新建主机」为首页唯一实心主按钮，将主机行内「连接」按钮降级为 Secondary 以减少视觉干扰；为 RDP、VNC 与串口的新建/编辑对话框补齐「保存并连接」一键闭环。
- **SSH / 本地终端**：基于绝对逻辑行 `LineAnchor` 修复流式输出期间缓慢拖选越过阈值前锚点漂移的问题；底栏有控件折叠进 `⋯` 菜单时显示清晰溢出提示与计数；强化分屏模式下活动与非活动窗格的视觉区隔并支持非活动窗格直接关闭。
- **RDP / VNC 远程桌面**：将浮层控件条与收起把手从右上角迁至顶部居中停靠，避开远端窗口右上角原生关闭/最大化按钮；收起后展开把手保持低干扰常显，点击不穿透远端画面。

## 反馈、本地化与边界稳定性

- 新增警告、信息与错误专属线条图标，替换 Toast 中以刷新/省略号/关闭图标代用的做法；抬高 Toast 栈底部偏移以避让终端/文件底栏右侧控件，并在栈清空时重置悬停状态。
- 补齐命令面板主机跳板/ProxyCommand 描述与启动失败阶段 2/3 存储报错的中英文完整本地化；为矮窗启动失败页补充键盘滚动与滚动提示，缓解单栏矮/窄窗下文件视图列表区垂直挤压。
- 修复跨平台标签溢出、紧凑通知宽度、macOS 弹窗入场动画及串口断连轮询等 CI 稳定性问题。
