# Shellune 0.4.15

## 全界面 UI/UX 交互与效率升级

- **终端与分屏体验**：终端搜索新增网格内全部命中项与当前命中项高亮，当前命中位于底部时搜索栏自动翻转至顶部避让且不触发 `SIGWINCH`；新增交互式滚动条轨道（支持点击跳转与拖拽定位历史输出）；分屏支持基于实测容器跨度的 1:1 指针拖拽、双击分屏线恢复 50:50 平分、放大态（`Active · Zoomed`）同步与还原按钮；支持双击标签页重命名及待启动标签中键关闭。
- **主机主页、表单与命令面板**：侧栏支持全键盘方向键导航与分组树折叠展开；主机多选栏新增批量删除与清单二次确认；新建/编辑连接表单支持跨协议保留地址与用户名、字段级内联报错高亮、已有分组快捷点选胶囊以及 `Ctrl+Enter` / `⌘↵` 保存并立即连接；命令面板在大量主机下仍均衡展示导航与全局动作，并纳入 RDP / VNC / 串口连接；快捷命令库支持实时搜索与快捷键直接执行。
- **SFTP 文件管理、传输、端口转发、批量任务与设置**：SFTP 双栏新增前往路径（工具栏与 `Ctrl/Cmd+G`）、一键复制当前目录路径、键盘上下选中跟随滚动、文件夹组合键多选及窄窗口单栏快速切换；传输条与传输中心新增一键清理已完成任务与运行中进度条；端口转发按运行阶段语义着色并支持点击复制监听地址；批量任务支持等宽字体输出、一键复制输出、按主机状态筛选与键盘切换主机；设置连接策略支持一键重置默认，同步页提示未保存修改，启动异常停留页补齐双按钮键盘焦点切换。

## 窗口与远程桌面稳定性修复

- **Windows 标题栏双击最大化**：Windows 原生接管空白标题栏拖拽区命中区域（`HTCAPTION`），单击保持窗口大小，仅双击才最大化或还原，保留正常拖动与贴靠行为；macOS 顶栏补齐原生拖拽控制区域。
- **VNC 空闲连接与远程桌面断开识别**：修复 Windows 下 VNC 空闲读取稳定性并细化远程桌面断开原因识别；完善远程桌面界面缩放适配、证书弹窗 `Esc` 拒绝及提示条交互。
