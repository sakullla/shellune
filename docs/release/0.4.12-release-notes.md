# Shellune 0.4.12

## 高延迟远程桌面

- VNC 和 RDP 支持在本机绘制远端提供的光标。移动鼠标时无需等待新画面，文本光标、拖动热点和隐藏状态随远端应用切换。未提供独立光标的服务端继续使用画面里的指针。
- 高延迟或窄带连接中，合并尚未发送的连续移动，保持按下、松开、滚轮和键盘操作的顺序。RDP 接收大块画面期间也能穿插发送输入。
- RDP 批量发送通道加入请求，VNC 建连减少一次往返。支持连续更新的服务器可在画面变化时主动推送，减少等待下一次画面请求的时间。

## 弱网实测

在模拟 8 秒往返延迟、每方向 64 kbit/s 的链路上，同一台 Linux 测试机完成了以下握手优化前后的对照。时间从开始连接计至收到首块桌面像素。

| 服务端 | 优化前 | 优化后 |
| --- | ---: | ---: |
| TigerVNC | 36.26 秒 | 28.33 秒 |
| xrdp 登录画面 | 74.88 秒 | 59.81 秒 |

TigerVNC 测试中，远端在 4.04 秒后收到了同一位置的按下和松开。客户端在点击后 8.49 秒收到了由这次点击触发的画面变化。服务器第一次将独立光标交给客户端后，后续移动可直接在本机显示。
