# Shellune 0.4.32

- 主机列表的“连接”按钮平时只显示文字、不带边框，鼠标指向或用键盘选中某一行时才显示按钮样式，长列表不再是一整列相同的按钮。
- 在主机搜索框输入关键词时，第一个匹配项会高亮并显示“回车”键帽，按回车即连接这一台；按 ↓ 直接跳到下一项。开启了“已连接”筛选时，回车连接的主机与列表第一行保持一致（之前远程桌面和串口会话可能导致不一致）。
- “全部主机”顶部新增“最近”一栏：列出最近连接过的主机，点击即可重新连接，悬停显示地址和上次连接时间，“查看全部”进入最近连接列表。按窗口宽度显示，最多 6 台；搜索、筛选、多选时，或主机少于 8 台、窗口较矮时不显示。
- 新增加密保险库：SSH 私钥和连接密码统一加密保存，主机只保存对它们的引用；旧版本的数据会自动迁移。
- 设置中新增“密钥和密码”页面：可导入、生成、导出 OpenSSH 密钥，管理共享的连接密码；查看密码和导出私钥需要再次确认。RDP 和 VNC 连接也可以使用保险库中的共享密码。
- 新增主机信任页面和本机保险库锁定，支持系统生物识别解锁。
- 同步和备份支持加密保险库：按记录合并，冲突时提示，并防止回滚到旧数据；导出包含保险库的备份需要先解锁。
