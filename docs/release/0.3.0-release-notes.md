# Shellune 0.3.0

**Shellune** — 连接远程，也专注本地。
A modern terminal for local shells, SSH, and SFTP.

这一版从使用者的角度重做了界面：去掉侧边栏，本机终端和服务器合到一个主页，连接、导入、
端口转发和文件传输都改成引导式弹窗或主机自带的工具，并重做了 SFTP 文件管理和端口转发。

## 界面重做

- **顶栏即标签栏**：顶栏同时是标题栏和标签栏，从左到右是「主机」主页、各终端标签、新建、搜索与设置。
  不再有侧边栏。
- **主机主页**：「本机」一行是 Shell 卡片，单击即在新标签打开；「服务器」一行是搜索和主机列表。
  还没有主机时显示首次使用引导，可直接新建或导入 SSH 配置。
- **设置页**：主题、语言、文字大小、动态效果、终端字号和默认 Shell 都在这里，`Ctrl+,`（macOS 为 `Cmd+,`）打开。
- **会话页已移除**：它和终端标签重复。
- **传输和端口转发成为主机工具**：从主机行、会话栏或命令面板以弹窗打开，不再占用导航菜单。

## 引导式弹窗

- **连接主机**：主机、地址和状态在弹窗顶部；选择登录方式时才显示引导；指纹确认和失败原因都在弹窗里。
  连接进行中可「转到后台」，以标签继续，点标签回到弹窗。
- 快速连接、导入 SSH 配置改为同样风格的弹窗。

## SFTP 文件管理

- 会话栏新增「终端 | 文件」切换，文件管理器占满终端区域，本机与服务器两栏并排（窄窗口时可切换）。
- 每个条目一行：图标、名称、大小（KB/MB），以及下载、复制到另一侧、重命名、删除等图标操作。
- 路径显示为可点击的面包屑；传输进度在底部。

## 端口转发

- 每条规则是一张卡片：类型、主机、状态与 `本机地址 → 目标`，一键启动或停止。
- 新建表单分「本地转发 / 远程转发 / SOCKS 代理」，各附一句用途说明；字段有标签与示例值，
  底部用一句话预览转发效果。

## 修复

- Windows：顶栏空白处可以拖动窗口（支持贴靠，双击最大化/还原）；最小化、最大化/还原、关闭按钮恢复响应，
  关闭仍会先确认进行中的传输与转发。
- 连接成功后键盘直接进入终端。
- 弹窗或表单关闭后焦点不再落空，快捷键保持可用。
- 未保存的快速连接主机在会话栏显示地址，而不是一串 ID；准备连接后快速连接表单自动关闭。
- 切换语言后输入框的占位文字跟着变化。

## 快捷键变化

- `Ctrl+1 / 2 / 3`（macOS 为 `Cmd`）对应 主机 / 终端 / 设置。
- 移除了会话、传输、转发页和侧边栏折叠的快捷键。

## 下载

- Linux x86_64：deb 安装包（amd64）。
