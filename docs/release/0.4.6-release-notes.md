# Shellune 0.4.6

**Shellune** — 连接远程，也专注本地。
A modern terminal for local shells, SSH, and SFTP.

这一版扩展了连接协议与工作区形态，加入批量任务中心、SFTP 并排双栏，并全面打磨了表单、主机列表、终端历史浏览与高缩放边界体验。

## 多协议连接与工作区

- **协议记录与表单**：主机目录支持 SSH、串口、RDP 与 VNC 连接记录，按协议提供对应连接表单、检索筛选与快捷操作。
- **串口会话**：在终端标签内打开串口设备，支持波特率/数据位/校验位/停止位配置、本地回显、换行符切换、重连与断开状态提示。
- **远程桌面工作区（RDP / VNC）**：支持连接阶段展示、证书确认、全屏与画面缩放、高延迟握手及帧内存预算控制（Windows 源码构建执行 `packaging/native/build_native.py` 静态链接 FreeRDP / LibVNCClient 后启用原生画面后端；未链接原生后端的构建会在标签内明确说明原因，RDP 剪贴板暂不支持并明确报告）。

## 文件与批量任务

- **SFTP 并排双栏与目录跟随**：窗口宽度充足时可将 SFTP 文件面板停靠在终端右侧，支持多选标记操作，并可通过 Shell 的 `OSC 7` 自动跟随当前工作目录。
- **批量任务中心**：拆分为任务库、编辑器、当前运行与历史记录；编辑草稿不触发连接，切换页面不中断后台执行。

## 交互效率与界面细节

- **全键盘表单流**：SSH 主机、协议连接、快速连接、登录凭据、端口转发、分组、快捷命令与连接策略输入框全面接通 `Tab` / `Shift+Tab` 焦点环与 `Enter` 提交；搜索与过滤框支持一键清空（`×`）；快速连接输入 `user@host:port` 时自动拆分用户名与端口。
- **主机列表与快捷操作**：统一卡片与列表模式的等宽连接目标与点击复制，支持 `↑` / `↓` / `Enter` 键盘导航、右键快捷菜单及宽屏行内一键克隆。
- **终端与高缩放适配**：新增终端右侧滚动位置条、历史浏览时的“跳到底部”浮动胶囊、右键“全选 / 跳到底部”以及底栏/设置页字号点击一键恢复默认值；修复 200% 缩放窄窗口下列表按钮裁切与短视口主页滚动边界。
