# Shellune 0.4.31

- 主机图标显示操作系统：连接 SSH 主机后，在单独的通道里读取一次 `uname` 和 `/etc/os-release`（Windows 读取 `ver`），之后该主机的图标显示对应系统的标志（Debian、Ubuntu、CentOS、Rocky、Alpine、Arch、macOS、FreeBSD 等），颜色仍按主机名区分。读取在后台进行，不会出现在终端里。可在“设置 → 外观 → 操作系统图标”关闭，关闭后不再向服务器读取。
- 标签栏的“+”和下拉菜单合并为一个按钮：点击后打开搜索框，可选择本地 Shell，也可以直接打开已保存的主机（最近连接的在前），输入 user@host:port 可直接临时连接；按回车打开默认 Shell。Ctrl+Shift+T 仍直接打开默认 Shell。
- 终端光标在获得焦点时闪烁，输入或有新输出时保持常亮；开启“减少动态效果”时不闪烁。
- 文件传输列表重新设计：每项显示方向、文件名、状态和操作，第二行显示来源和目标；已完成的下载可以“在文件夹中显示”，已结束的任务可以单独移除；已完成的任务不再显示“续传”按钮和偏移量，可续传位置改为“可从 2.0 KB 处续传”；只有使用 SCP 时才显示协议标签；标题旁的数字改为任务总数，有任务进行中时显示进行中的数量。
- 修复对话框里的列表（如端口转发的主机选择）滚动时整个对话框一起滚动的问题：内层列表先滚动，滚到底后才滚动外层。
