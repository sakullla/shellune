# Shellune 0.4.4

**Shellune** — 连接远程，也专注本地。
A modern terminal for local shells, SSH, and SFTP.

这一版重新设计了终端页的顶部与底部，并让连接直接在标签里进行。

## 终端页

- **顶部只留标签**：本地终端和 SSH 会话的顶部完全一致，只有标签和应用按钮，不再夹带路径与会话工具。修复标签名在部分缩放下被截成省略号的问题。
- **会话信息移到底栏**：连接地址（或本地 Shell 路径）、连接状态，以及文件、分屏、更多菜单都在终端底栏，和搜索、复制、字号放在一起。需要处理时，"重新连接""保存主机"按钮出现在底栏。
- 不再显示默认的"X11 关"和与标签重复的"SSH 远程"。

## 连接

- **点"连接"直接进入标签**：新标签立即打开，连接进度、指纹确认、失败原因和重试都显示在终端区域，不再弹出盖住主页的对话框；只有需要先填写凭据时才弹出对话框。
- "转到后台"会回到主机页，连接在标签里继续进行。
- 网络超时等与登录无关的失败，只给"重试"和"修改登录方式…"，不再直接展开整个登录表单。

## 复制

- 地址、路径、主机指纹、连接失败原因、端口转发规则等，点击即可复制，并提示"已复制"。

## 其他

- 批量任务里的输入框去掉了重复的边框。
- 修复 macOS 上"关闭应用时确认正在进行的传输"测试的问题。

## 下载

- Windows x86_64：便携 ZIP 和 NSIS 安装包。
- macOS Apple Silicon：DMG 安装镜像，使用项目固定证书签名，未经过 Apple 公证。
- Linux x86_64：deb 安装包（amd64）。

Windows 和 Linux 构建未签名。发布附件由各平台 CI 构建，并附 SHA256SUMS。
