# Shellune 0.4.28

- 文件页的列表单独滚动：路径、筛选框和表头固定在顶部，列表带滚动条；窗口很矮时列表至少保留两行，再不够才整列滚动。
- 文件列表新增“修改时间”列，显示“5 小时前”这样的相对时间，可以排序，第一次点击最新的在前；栏位较窄时自动隐藏。大小改为右对齐，文件夹不再重复显示“文件夹”。
- 路径始终显示在一行：深层路径保留根目录和最近两级，中间折叠为“…”，点击可编辑完整路径；过长的文件夹名用省略号截断，悬停显示完整路径。
- 未筛选时数量显示为“24 项”；以“.”开头的隐藏文件文字稍淡。
- 修复连接页确认服务器指纹时，“取消连接”和“在后台继续”按钮显示在卡片外面的问题。
- 终端只要有历史记录就显示一条较淡的滚动条，悬停时加深，可以拖动。
