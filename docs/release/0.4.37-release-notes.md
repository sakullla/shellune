# Shellune 0.4.37

- WebDAV 同步按记录合并：每次同步成功后在本机保存一份「上次同步的共同版本」，此后两边都有修改时逐条记录、逐个字段三方对比——两边改的是不同主机、不同字段时自动合并，不再整体报冲突；只有同一字段两边改成了不同的值（或一边删除、一边修改）才算冲突。共同版本与上次同步记录不符时绝不拿来合并。
- 冲突终于说清楚在哪：冲突弹窗逐项列出「类型 · 记录名 · 字段」以及本机值与云端值（例如「SSH 主机 · web · 地址：本机 10.0.0.3 / 云端 10.0.0.2」），每一项可单独选择保留哪一边，也可「全部用本机 / 全部用云端」；全部选定后一次性上传并应用。没有共同版本（如首次同步）时也会列出差异位置，再整体选择一边。
- 服务器不提供强 ETag（部分 WebDAV 服务）时，上传前会重新读取云端文件；若其他设备刚好写入，会重新判断并合并，不再盲目覆盖。
- 密钥文件移入密码库：使用本机密钥文件（identity_file）登录的连接在其他设备、其他平台上无法使用。密码库页会提示并可一键「移入密码库」——读取密钥（加密密钥使用已记住的口令解开）、按指纹去重存入密码库、连接改为使用密码库密钥并清除本机路径，一次原子保存；无法读取或解开的文件会逐个列出且保持原样。主机编辑弹窗中也可对单个密钥文件「移入密码库」。
- 密码库安全加固：复制的密码 30 秒后自动从剪贴板清除（剪贴板已被你复制的其他内容替换时不动）；显示的密码 30 秒后自动隐藏；新建/编辑密码时显示强度条与估算位数，识别常见密码与重复/连续模式；生成的密码保证包含每一种勾选的字符类型，且无法取消最后一种。
- 新增「需要关注」筛选：列出低于 3072 位的 RSA 密钥与弱密码，并在详情中说明原因与建议；密钥列表以「Ed25519 / RSA 2048 / ECDSA P-256」标注类型与长度，取代笼统的「SSH 密钥」。
- 主机信任列表直接显示完整指纹（搜索命中高亮）并提供复制按钮，便于与服务器 `ssh-keygen -lf` 输出核对；详情中的「删除」按钮使用危险样式。
- 顶部「主机」固定标签改为仅显示图标（名称、数量与快捷键在悬停提示中），为会话标签让出空间；中文界面统一使用「密码库」称呼。
