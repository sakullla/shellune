# Shellune 0.4.38

- 修复同步报错「the cloud holds an older vault (version N) than this machine already applied」：在冲突中选择「以本机为准」时，写回云端的密码库版本号只按本机计算，可能低于其他设备已应用的版本，导致其他设备从此拒绝同步。现在每次写入密码库都以「本机、云端、上次同步」三者中的最高版本再加一，绝不会让其他设备看到回退；按记录合并时保留较旧副本的情况同样处理。
- 已经遇到该报错的设备可一键「合并修复」：同步设置中会说明原因并提供按钮——两边的密码库逐条合并，每条记录保留版本更新的一边、只有一边有的记录保留，两边各自改成不同内容的记录由你选择，随后以高于所有版本的版本号写回云端，其他设备即可继续同步；不会丢弃任何一边的记录。
- 该报错改为中文说明（含云端与本机的版本号），并且不再提示「会自动重试」——自动重试无法解决此类问题。
