# Shellune 0.1.0

**Shellune** — 连接远程，也专注本地。
A modern terminal for local shells, SSH, and SFTP.

Shellune 读作 Shell-loon，由 Shell（终端）与 Lune（月亮）组合。

## 这一版包含

- 本地终端：可选的 PowerShell / CMD（Windows）或系统 Shell（macOS、Linux），真实
  PTY，颜色、光标、备用屏幕、中文文本、鼠标选择复制、回滚、字号与窗口尺寸调整。
- SSH 会话：密码、未加密私钥、带口令私钥；未知主机展示算法与 SHA-256
  指纹，身份变化明确阻断且不覆盖旧记录。连接也支持系统 SSH Agent，但 **0.1.0 没有验证
  系统 Agent 登录**：本机 OpenSSH 认证代理服务被禁用（`sc start ssh-agent` 返回 1058），
  无 Pageant，因此这条路径只有代码与表单，没有一次成功的真实登录（见
  `0.1.0-verification.md` 2.4 与 7.2）。
- 主机管理：创建、编辑、删除、搜索、分组、最近连接，版本化原子存储。
- SSH 配置导入：只读导入 `Host`/`HostName`/`User`/`Port`/`IdentityFile`
  的明确子集，保留来源与行号；`Include`、`Match`、通配、`ProxyJump`、
  `ProxyCommand`、转发等形成明确的部分导入结果与复核标记。
- 多会话：本地与不同远程主机同时打开，按会话隔离事件，手动重连不重放命令。
- SFTP：同一已认证连接上的目录浏览、新建目录、重命名、删除（含递归确认）、上传与
  下载；临时文件 + 显式覆盖 + 可取消任务，失败不显示成功。
- 界面：左侧图标侧边栏导航四个目的地（本地终端、主机、会话、传输）；终端打开后头部即
  标签栏，"新建本地终端"与 Shell 菜单合为拆分按钮；空的本地终端页是欢迎页，一键启动
  检测到的 Shell。暗色令牌化主题，90% / 100% / 115% 文字大小，中文与英文界面
  （Ctrl+L 切换；终端内该键属于 Shell，语言改由侧边栏底部的语言控件切换）。
- 命令面板（Ctrl+Shift+P / ⇧⌘P，终端内可用）：一处搜索并切换已打开的会话、启动 Shell、
  连接已保存主机、前往各页面，以及关闭会话、新建主机、导入 SSH 配置、切换语言与文字大小。
- 标签操作：Ctrl+Shift+W 关闭、Ctrl+PgDn / Ctrl+PgUp 切换、Alt+1-8 直达、Alt+9 最后一个
  （macOS：⌘W、⇧⌘] / ⇧⌘[、⌃1-9）；中键关闭；右键菜单可复制标签、关闭其他或右侧标签，
  有传输进行中的会话会先询问。

## 这一版不包含

- 终端分屏（同一工作区平铺多个可交互终端）。
- 跳板机 / ProxyJump 连接管理；导入到相关配置时只给出限制提示。
- 端口转发（本地、远程、动态）的配置与管理。
- 文件断点续传；中断后重新发起是一次新传输。
