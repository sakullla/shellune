# Shellune 0.4.3

**Shellune** — 连接远程，也专注本地。
A modern terminal for local shells, SSH, and SFTP.

这一版从使用者的角度重做了连接、新建主机和设置三处体验。

## 连接

- **连接过程一目了然**：连接弹窗改为四步进度（连接服务器 → 验证服务器身份 → 登录 → 打开终端），显示当前进行到哪一步、连的是哪个地址、用什么方式登录；需要你确认服务器指纹等问题时，对应步骤会标出"等待你操作"。
- **连接失败更好处理**：先告诉你下一步该怎么做，原始报错作为详情放在下面；只保留一个"重试"按钮，可以先换一种登录方式再重试。服务器身份发生变化时不提供重试。
- X11 转发选项收进"更多选项"。

## 新建主机

- **新增"自动"登录方式（默认）**：依次尝试系统 SSH Agent、`~/.ssh` 下的默认私钥（id_ed25519、id_ecdsa、id_rsa），最后使用你填写的密码（可不填）。大多数服务器不用再手动选择登录方式。
- 表单按使用顺序排列：地址、用户名、登录方式在前，名称和分组可选——名称留空时以地址命名。
- 在地址栏粘贴 `root@10.0.0.12:2222`，会自动拆分出用户名和端口。
- 跳板机、代理命令、启动命令、文件传输、X11、保活收进"高级设置"，用到了其中任何一项时会提示并默认展开。
- "带口令的私钥"合并到"私钥文件"下的一个复选框。

## 设置

- 设置改为**一整页连续滚动**：所有分类依次排列，可以一路往下看完；左侧导航随滚动高亮当前分类，点击即可跳到对应位置。

## 修复

- 修复 macOS 上几项测试因测试平台不支持隐藏应用而失败的问题。
