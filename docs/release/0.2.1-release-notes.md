# Shellune 0.2.1

这一版补齐应用图标并修复 Windows 启动时出现额外命令行窗口的问题，保留 0.2.0 的主题、主机管理和自定义标题栏。

## 改进与修复

- 新增月蓝、淡紫色的新月应用图标，统一应用内品牌、Windows 程序与任务栏图标，并接入 macOS、Linux 打包资源。
- Windows 程序使用 GUI 子系统启动，不再附带 CMD / 控制台窗口。
- 保留顶部拖动、最小化、最大化 / 还原和关闭的原生窗口控制区域；应用使用普通窗口层级，不启用置顶。
- 提供可复用的图标生成脚本，支持从已保存源图离线重建 PNG、ICO、ICNS。

## 下载

- Windows x86_64：便携 ZIP 和 NSIS 安装包。
- macOS Apple Silicon：应用 ZIP，使用项目固定证书签名，未经过 Apple 公证。
- Linux x86_64：tar.gz。
