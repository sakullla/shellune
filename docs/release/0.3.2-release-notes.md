# Shellune 0.3.2

**Shellune** — 连接远程，也专注本地。
A modern terminal for local shells, SSH, and SFTP.

这一版让终端支持鼠标、拖放文件和粘贴图片，增强了 SFTP，并用统一的提示替代了常驻的结果卡片。

## 终端

- **鼠标**：vim、htop、tmux 等程序开启鼠标后，点击、拖动和滚轮都会发给程序（支持 SGR、UTF-8 与 X10 编码）；按住 Shift 仍可由终端选择文本。less、man 等全屏程序中滚轮转为上下方向键。
- **选择**：双击选词，三击选整行，选中即复制。
- **右键菜单**：复制、粘贴、搜索；中键粘贴。
- **拖放文件**：拖到本地终端填入加引号的路径；拖到 SSH 终端先上传到服务器，再填入远端路径。
- **粘贴图片**：本地会话把 Ctrl+V 交给程序，由程序自己读取剪贴板图片（如 AI 命令行工具）；SSH 会话把图片上传到服务器后填入远端路径。
- **配色**：状态栏、搜索条、粘贴确认与右键菜单随终端配色，深色终端在浅色界面中也是整块深色。

## SFTP

- **右键菜单**：条目上可打开、复制到另一侧、下载到…、重命名、复制路径、删除；空白处可新建文件夹、上传、刷新、复制当前路径。Windows 上复制的是 `C:\…` 写法。
- 从系统文件管理器把文件拖到服务器一侧即上传到当前目录。
- 每行的操作图标只在悬停或选中时显示；去掉常驻说明行；传输条只在有传输时出现；传输方向显示为中文。

## 提示

- 新增右下角提示（toast）：文件改动成功、上传/下载完成、开始上传、复制路径、上传失败。成功约 4 秒、问题约 9 秒后消失，悬停时暂停，可随时关闭，不占用页面空间。
- 文件改动部分失败时，逐项原因仍留在列表旁。
