# Shellune 0.4.26

- 主机列表、侧边栏分组、对话框、设置页和命令面板加上可拖动的滚动条：内容超出时显示细滑块，悬停时加宽，可以拖动，也可以点击轨道直接跳到对应位置，和终端的滚动条外观一致。
- 新建或编辑主机时，“分组”改为下拉选择框：只在分组输入框获得焦点时出现在输入框正下方，浮在表单上方，不再把下面的内容挤开；输入时按每个词过滤并排序，高亮命中的文字，显示每个分组下的主机数量；输入的新路径会显示“新建分组”选项；列表可以滚动，支持上下键选择、回车选中、Esc 收起（不会关闭对话框）。
- 侧边栏分组的图标和数量与上方“全部主机”等项目对齐：没有子分组时不再预留折叠箭头的位置，“更多”按钮在悬停时显示在数量的位置。
- 主机列表不再在每个 SSH 主机后显示“SSH”标签，只有 RDP、VNC 和串口连接显示协议标签；在侧边栏选中某个分组时，不再重复显示每行的分组列。
