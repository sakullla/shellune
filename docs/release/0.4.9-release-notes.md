# Shellune 0.4.9

**Shellune** — 连接远程，也专注本地。
A modern terminal for local shells, SSH, and SFTP.

这一版按“简单、好用”的方向重做了整个应用的界面和交互。远程桌面（RDP / VNC）现在可以和本机互通剪贴板，RDP 还能映射本机文件夹。0.4.8 中在文件操作里弹出确认框会导致应用退出，这个问题已修复。

> **升级提醒**：0.4.9 会在主机列表和同步数据里写入新字段，例如某台主机关闭了剪贴板共享。0.4.8 及更早的版本读到这些字段时，会拒绝整个主机文件或同步文件。如果你在多台设备之间同步，请把所有设备都升级到 0.4.9。

## 修复

- **文件操作导致闪退**：0.4.8 中，在文件页的筛选框输入内容后，再进行重命名、新建、删除等需要确认的操作，应用会直接退出。现已修复。

## 界面与交互重做

- **启动**：品牌页下方的进度条对应真实的四个加载阶段，加载完成后才进入首页。某个阶段失败时会停下来，说明是哪一步、为什么失败，并提供“继续”和“打开配置文件夹”两个按钮。
- **首页**：左侧栏放全部主机、收藏、最近连接和分组，右侧是一个主机列表，主机数量很多时也能流畅滚动。搜索框同时用于搜索和直接连接，输入 `user@host:port` 后回车即可连接。各种协议的连接都会出现在分组中，分组支持键盘操作：F2 重命名，Delete 删除，“⋯”打开更多操作。
- **终端选择**：鼠标按在字符的哪一半，选区就从哪一边开始，拖动第一个字符也能准确选中。拖动超过 3px 才开始选择，避免误选。支持 Shift 扩展选区和 Alt 块选；拖到窗口边缘时会自动滚动；拖出窗口后仍能继续选择。
- **断开与失败提示**：改为终端上方的一条横幅，不再遮住终端内容。横幅包含一句说明，以及重新连接、关闭和详情按钮。展开的诊断信息可以复制、可以滚动，最多占窗格约 40% 的高度。
- **标签和底栏**：标签按标题长短自适应宽度，“全部标签”按钮紧挨着标签，只在放不下或紧凑模式下出现。终端底栏只保留状态、文件、分屏、搜索和“⋯”。
- **文件与传输**：重命名、新建、上传等操作改为轻量的内联表单，不再重复显示路径。“跟随终端目录”改为头部的一个小开关。
- **对话框与设置**：
  - 全应用的按钮顺序统一为主按钮在最右。
  - 新建或编辑主机时，表单分为“基本信息 / 登录方式 / 高级”三组，Tab 键按显示顺序移动。
  - 跳板机和端口转发的“经由主机”改为可搜索的下拉框。
  - 设置页改为左侧导航，右侧是分组卡片。
- **细节**：
  - 文字被截断时都会显示省略号，并有完整内容的提示。
  - 空状态的说明文字不再与按钮重叠。
  - 在 720×480 窗口和 200% 字号下，主要页面仍然可用，输入框的占位文字也会随字号放大。

## 远程桌面：剪贴板与文件

- **RDP**：本机和远端之间可以互相复制粘贴文本和图片。在连接设置中填写“映射本机文件夹”后，远端可以在资源管理器里看到并读写这个文件夹。映射的文件夹只能访问它自身的内容，通过符号链接或目录联接都访问不到它以外的文件。
- **VNC**：可以互相复制粘贴文本，支持中文等非西文字符（需要服务器支持 UTF-8 剪贴板扩展；不支持时只发送西文文本，并给出提示）。
- 每台主机都可以单独关闭“共享剪贴板”。会话真正连上之后才开始共享剪贴板。
- 遇到以下情况时，界面会给出提示：服务器拒绝剪贴板或文件夹映射；文本超过 1 MiB，截断后发送；图片超过 32 MiB，不传输。
- 同时复制了文本和图片时，粘贴到终端里的是文本。
- Windows、macOS 和 Linux 的发布包都包含 RDP / VNC 原生库及其第三方许可证。

## 已知限制

- 剪贴板和文件夹映射还没有在真实的 RDP / VNC 服务器上全面测试。
- Wayland 下不能把远端的图片写入本机剪贴板。X11 下超过约 16 MiB 的图片无法传输。
- VNC 服务器发来超过 1 MiB 的文本时，libvncclient 会断开连接。
- 如果 RDP 服务器始终不回应文件夹映射，不会有任何提示。
- 剪贴板与键盘输入走不同的通道，两者之间没有顺序保证。
- 在 720×480 窗口和 200% 字号下：
  - 启动失败页的失败原因要往下滚动才能看到；
  - 文件页的列表区域很小。
- 启动失败时，失败原因的文字在中文界面下仍是英文。
- WebDAV 同步还没有在真实服务器上全面测试。浅色主题在 Windows 启动时可能闪一帧黑色。

## 下载

- Windows x86_64：便携版 ZIP 和 NSIS 安装包。
- macOS Apple Silicon：DMG 安装镜像，使用项目固定证书签名，没有经过 Apple 公证。
- Linux x86_64：deb 安装包（amd64）。

Windows 和 Linux 的构建没有签名。所有发布文件都由各平台的 CI 构建，并附带 SHA256SUMS；应用内更新用到的文件都附带 minisign 签名。
