# Shellune 0.4.10

## 远程桌面

- RDP 和 VNC 客户端已集成到 Shellune。VNC 支持 Hextile 编码，低带宽下可以分段显示画面。连接较慢时，窗格会显示当前阶段和等待时长。
- 证书确认窗口分别列出主机、证书持有者、颁发者和 SHA-256 指纹。点击可复制完整指纹，也可用键盘选择信任或拒绝。
- 远程桌面可以适应窗口大小。点击缩放读数可在适应窗口与原始大小之间切换，工具栏可收起。修复了平移后点击位置偏移、触控板小幅滚动丢失及部分 RDP 会话重复输入的问题。
- 持续更新画面时会释放旧纹理。关闭连接后，后台负责等待网络线程退出，减少慢连接对窗口操作的影响。

## 终端与窗口

- 本地和 SSH 终端支持当前会话的历史命令建议。Tab 仍交给当前 shell，可用于补全远端路径。
- 新建主机时，切换 SSH、RDP、VNC 协议保留对话框位置，避免整窗闪烁。RDP 和 VNC 表单支持输入、查看和记住密码。
- 已移除固定的最小窗口尺寸。原先设置为 200% 的应用字号会恢复为 100%，远程桌面画面仍可独立缩放。

## 截图与验证

- 默认截图预览生成主机列表、本地终端、RDP 桌面三张图。可以单独指定场景，PNG 发布前校验改为分块读取，减少内存占用。
- 在 4 秒往返延迟、每方向 128 kbit/s 的测试链路上，TigerVNC 连续两次绘出完整的 1280×800 桌面，并从服务端读回了键盘输入、鼠标位置和剪贴板文本。相同网络条件下，xrdp 也返回了画面。此次实机验证使用 Linux 服务端。
