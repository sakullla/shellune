# Shellune 0.4.8

**Shellune** — 连接远程，也专注本地。
A modern terminal for local shells, SSH, and SFTP.

这一版重做了整个应用的界面，修好了“重新连接会新开标签”的问题，并加入应用内自动更新、备份导入导出与 WebDAV 同步。

## 界面重设计

- **新的设计语言**：重新调配深色 / 浅色两套配色，表面分层、柔和阴影和圆角卡片；正文在所有表面上的对比度不低于 4.5:1。开关、勾选框、对话框、菜单、提示条统一为共享控件。
- **浏览器式标签**：当前标签与页面相连；连接状态用小圆点表示，标题过长时显示省略号，不再溢出标签；标签多时可横向滚动，也可从“全部标签”列表打开。窄窗口或大字号下标题栏自动收紧，更新、同步提示收成图标。
- **终端**：断开或失败时，画面中央显示状态卡片和“重新连接”；底栏分组，宽度不够时工具收进“⋯ 更多”。
- **首页**：快速连接栏、最近连接、收藏和分组卡片、主机列表按新样式重绘；本地终端移到“本地终端 ▾”菜单。
- **设置与对话框**：设置页改为导航面板加分组卡片，开关类设置使用开关控件；所有对话框统一外观，有进入动画，关闭时遮罩淡出。删除确认和关闭询问打开时，按键不会落到背后的终端或搜索框。
- **其余界面**：文件 / SFTP、远程桌面、串口、转发、批量任务、命令面板和所有菜单都换成新样式。
- **启动画面**：改为简短的品牌过场，数据在后台加载，完成后淡入首页或恢复的工作区。系统或应用开启“减少动态效果”时直接进入。
- **无障碍**：720×480 窗口、200% 字号下，标签、底栏、分屏、状态卡片仍然可见、可点。

## 连接

- **重新连接留在原标签**：断开或失败的会话重连时，在原标签 / 原窗格内进行，不再新开标签。新增标签右键菜单、命令面板入口和快捷键 `Ctrl+Shift+R`（macOS 为 `⇧⌘R`）。
- 在其它连接进行时后台失败的重连，从它的表单重试也会回到原标签。

## 更新、备份与同步

- **应用内自动更新**：检查、下载并校验（minisign 签名）新版本，确认后安装；可在 设置 → 关于与更新 中关闭自动检查。
- **备份导入 / 导出**：导出主机、分组、片段、设置等数据；可选择包含密码，密码使用口令加密（Argon2id + AES-GCM）。导入前先预览。
- **WebDAV 同步**：默认开启，可关闭。跨操作系统同步主机与设置；两边都有改动时弹出冲突确认，仅“最近连接”不同时自动合并，不再询问。

## 已知限制

- RDP 尚不支持剪贴板；VNC 仅支持文本剪贴板，非 ASCII 字符可能乱码。两者都不支持文件传输。
- WebDAV 同步尚未在真实服务器上全面验证；`http://` 地址为明文传输。
- 浅色主题在 Windows 上启动时可能仍有一帧黑色；macOS / Linux 无此项处理。

## 下载

- Windows x86_64：便携 ZIP 和 NSIS 安装包。
- macOS Apple Silicon：DMG 安装镜像，使用项目固定证书签名，未经过 Apple 公证。
- Linux x86_64：deb 安装包（amd64）。

Windows 和 Linux 构建未签名。发布附件由各平台 CI 构建，并附 SHA256SUMS；应用内更新文件均附 minisign 签名。
