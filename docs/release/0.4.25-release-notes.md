# Shellune 0.4.25

- 深色与浅色主题的主文字、次要文字拉开层级，输入框占位符改用单独的更淡颜色，不再和已填写的值混淆。所有文字仍满足 WCAG 4.5:1 对比度。
- 主机列表只在确有主机设置了分组或有最近连接记录时才显示对应列，窄窗口下主机名不再被截断；只有列表里混有 RDP、VNC 或串口连接时才在每行显示协议标签。标题旁的主机数量改为胶囊标签。
- 导入 SSH 配置：打开时直接预览默认的 `~/.ssh/config`；“导入”按钮固定在弹窗底部；列表改为分隔线样式；已保存的同名主机标为“已保存”，按钮上的数量只计算真正会导入的主机；读取出错时也能取消。
- 导入完成提示使用正确的单复数，并省略为 0 的项，例如“Imported 8 hosts”。
- 命令面板用主题色高亮搜索命中的文字，搜索框与面板融为一体。
- 新建主机时的协议选择（SSH、RDP、VNC、串口）改为等宽平分。
