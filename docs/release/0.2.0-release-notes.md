# Shellune 0.2.0

**Shellune** — 连接远程，也专注本地。
A modern terminal for local shells, SSH, and SFTP.

这一版主要改进日常使用的界面与交互：保存主机可以记住密码、一键连接，输入框支持完整的编辑操作，
新增浅色主题、可折叠侧边栏和自定义标题栏。

## 新增

- **命令面板**（Ctrl+Shift+P / ⇧⌘P，终端内可用）：在一处搜索并切换已打开的会话、启动 Shell、
  连接已保存主机、前往各页面，以及执行常用操作（关闭会话、新建主机、导入 SSH 配置、切换语言 / 主题 /
  文字大小、折叠侧边栏）。
- **标签页**：Ctrl+Shift+W 关闭、Ctrl+PgDn / Ctrl+PgUp 切换、Alt+1-8 直达、Alt+9 最后一个
  （macOS：⌘W、⇧⌘] / ⇧⌘[、⌃1-9）；中键关闭；右键菜单可复制标签、关闭其他或右侧标签。
- **主机弹窗**：新建 / 编辑主机改为居中弹窗。可选登录方式（密码 / 私钥 / 带口令私钥 / 系统 Agent），
  只显示所选方式需要的字段。
  - **记住密码 / 口令**：保存在系统凭据库（Windows 凭据管理器、macOS 钥匙串、Linux Secret
    Service），不会写入主机文件；取消"记住"或删除主机时一并删除。
  - **连接后运行**：每次连接成功后，在远程 Shell 中自动执行一次指定命令。
  - 登录信息齐全的主机点"连接"即直接连接，连接成功后自动切到它的终端。
- **会话管理**：本地终端 / 会话列表中的会话可打开、复制、重新打开、关闭、删除，支持右键菜单；
  列表顶部可一键清除已关闭的会话。从侧边栏进入"会话"页时显示全部会话的列表。
- **输入框**：点击定位、拖动选择、双击选词、三击全选；Shift+方向键扩展选区，按词移动与删除；
  复制 / 剪切 / 粘贴 / 全选（快捷键与右键菜单）；密码框可临时显示内容；路径输入框有"浏览…"按钮，
  调用系统文件选择框。
- **浅色主题**：跟随系统（默认）/ 浅色 / 深色，在侧边栏底部或命令面板切换；终端配色同步切换。
- **可折叠侧边栏**：折叠为图标栏（按钮、Ctrl+Shift+B / ⌘B 或命令面板）。
- **自定义标题栏**（Windows、macOS）：应用顶行即标题栏，空白处可拖动窗口；Windows 自绘最小化 /
  最大化 / 关闭按钮，保留系统的贴靠布局。Linux 保留系统标题栏。

## 修复

- 从 SSH 配置导入的私钥路径（如 `~/.ssh/id_ed25519`）中的 `~` 现在展开为用户主目录；此前在
  Windows 上会报"系统找不到指定的路径"。
- SSH 连接失败时的"下一步"提示随界面语言显示中文。
- 进程快速退出时，最后几行输出不再丢失。
- 关闭标签或弹窗后键盘焦点不再丢失（此前之后的快捷键全部无效）。
- 侧边栏的会话数量只统计未关闭的会话，与标签一致。

## 这一版不包含

- 终端分屏。
- 跳板机 / ProxyJump 连接管理、端口转发、文件断点续传。

| Windows 11 | x86_64 | CI 构建并通过全部自动化测试；自定义标题栏的拖动、贴靠布局与窗口按钮未在真机上手动验证 |

以下功能依赖桌面环境，本版没有在真机上验证：系统文件选择框、各平台系统凭据库中的密码读写。

## 签名

- **macOS**：使用固定的自签名证书签名（`Shellune Code Signing`），**未经 Apple 公证**。首次打开时
  在 Finder 中右键 Shellune.app 选择"打开"，或在"系统设置 → 隐私与安全性"中选择"仍要打开"。
  之后的版本使用同一证书，已授予的钥匙串访问在升级后保留。
- **Windows**：未签名，首次运行会出现 SmartScreen 提示。
- **Linux**：压缩包没有签名；可用发布页的 `SHA256SUMS` 校验下载。
