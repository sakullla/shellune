# Shellune 0.4.30

- 主机图标的字母在所有已保存的主机中尽量不重复：先用原来的首字母，被占用时依次改用首词的前两个字母、首字母加后面某个词的首字母等。例如 bero-de-bf、bitsflow-de、bitsflow-de-xl 分别显示为 BD、BI、BX。已有主机的字母不会因为新增主机而改变。图标颜色改为按完整名称计算，并扩充到 12 种，名称相近的主机也容易区分。
- 终端会为普通输出中的 IP 地址（含端口、网段和 IPv6）、链接，以及 error、failed、refused 和 warning、deprecated 等字样着色；程序自己设置的颜色和全屏程序（vim、htop 等）保持不变。可以在“设置 → 终端 → 高亮输出内容”中关闭。
- 主机列表的筛选菜单改为紧凑面板：协议、状态、排序各占一行，选项并排可见；选择后面板保持打开，可以连续组合条件。
