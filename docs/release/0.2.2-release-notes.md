# Shellune 0.2.2

**Shellune** — 连接远程，也专注本地。
A modern terminal for local shells, SSH, and SFTP.

这一版补齐远程工作的主要能力：多跳 SSH、端口转发、分屏窗格、双栏文件与传输中心，
并打磨了终端外壳与日常操作的细节。

## 新增

- **多跳 SSH（跳板主机）**：在主机弹窗里按顺序添加跳板，连接可随时取消；中途断开时说明断在哪一跳。
  支持 ProxyCommand（只保存命令文本，执行前需确认）；导入 SSH 配置时先预览再导入。
- **端口转发**：本地、远程与动态（SOCKS）转发规则，按主机保存；启动前不监听，对外暴露的地址需确认，
  关闭仍在转发的会话或窗口时先询问。
- **分屏窗格**：左右 / 上下嵌套分屏，可拖动或点箭头调整比例、放大当前窗格；布局在下次启动时恢复为
  待连接窗格，恢复时不会自动运行 Shell、连接或监听端口。
- **双栏文件视图**：在已登录的会话上并排浏览本地与远程目录，上传、下载、删除与重命名。
- **传输中心**：集中显示上传与下载的进度；断线后可校验续传或重新开始。
- **Shell 命令块**：按命令分段显示输出，支持历史搜索；多行粘贴先确认。
- **统一会话工作区**：本地与远程会话在同一个工作区和标签栏里管理。
- **偏好会被记住**：主题、语言、文字大小、动态效果、侧边栏折叠和终端字号在下次启动时恢复。
- **全部启动**：恢复的布局里有多个待连接的本地窗格时，一次全部启动。

## 改进

- 文字大小最高可到 200%，并提供应用内的"减少动态效果"设置。
- 只有一个窗格时不再重复显示窗格标题和边框，分屏按钮移到会话栏，终端多出一行可用空间。
- 主机行只保留"连接"一个文字按钮，转发、编辑、删除改为带提示的图标；删除悬停时显示危险色，仍需确认。
- 主机弹窗的跳板列表带序号与排序箭头，可添加的主机改为可换行的紧凑按钮，主机多时表单不再被撑长。
- 导航项的焦点环只在键盘操作时显示，鼠标点击不再出现多余的蓝框。
- 文件栏随文字缩放适配窄窗口。

## 修复

- 点击待连接窗格的"连接"后，键盘直接进入新终端，不必再点一次。
- 空的会话页不再同时出现"没有打开的窗格"提示与空状态卡。
- 分隔条上的调整箭头按实际移动方向显示。
- 关闭标签或启动失败时保留待连接窗格；断线后保留较新的传输检查点；本地文件名限制在打开的目录内；
  关闭信任确认前先取消该连接。
