# Shellune 0.4.0

**Shellune** — 连接远程，也专注本地。
A modern terminal for local shells, SSH, and SFTP.

这一版重做了界面，并新增 X11 转发、SCP 传输、快捷命令库、终端内搜索、标签命名与后台提醒，以及可自定义的快捷键。

## 全新界面

- **配色与层次**：深色、浅色两套配色重新调校，主色改为靛紫；卡片、对话框为带细边框与轻阴影的凸起层，分段控件改为凹槽加滑块。
- **会话栏一行化**：名称、地址、状态在左，分屏、终端/文件、端口转发与关闭在右；窗口较窄或大字号时自动分两行。终端状态栏与终端同底色。
- **主机主页**：主机以 1–3 列卡片网格展示；本机 Shell 卡片使用品牌渐变图标；搜索框带放大镜图标。
- **顶栏**更紧凑，当前标签为凸起胶囊样式。
- **对话框**统一为大圆角凸起样式，连接对话框的头部显示主机头像、标题与状态。
- 修复设置页"动态效果"选项溢出卡片的问题。

## 终端

- **终端内搜索**：在滚动历史中搜索，支持字面/正则、区分大小写、上一处/下一处，计数实时更新；关闭后回到搜索前的位置。
- **标签**：可重命名、可设辨识色；"全部标签"列表在标签过多时也能找到每个标签。
- **后台提醒**：非当前标签收到响铃或命令结束时，在标签上标出"响铃"/"结束"，可在设置中分别开关。
- **快捷命令**：本地保存常用命令，一键填入或执行。

## SSH

- **X11 转发**：默认关闭，可按连接选择受限（-X）或信任（-Y）；失败时说明原因与下一步。
- **SCP 传输**：服务器没有 SFTP 时可用传统 SCP 复制文件与目录（递归需明确选择）。
- **导入 SSH 配置**改进。

## 键盘

- 所有应用动作集中到一个动作目录，可在设置中改键、解除绑定或恢复默认；菜单与提示中的组合键始终是当前生效的绑定。

## 下载

- Windows x86_64：便携 ZIP 和 NSIS 安装包。
- macOS Apple Silicon：DMG 安装镜像，使用项目固定证书签名，未经过 Apple 公证。
- Linux x86_64：deb 安装包（amd64）。
