# Shellune 0.4.43

- 终端滚动和重绘时减少了逐字符的内存分配。搜索长日志时，同一行出现多次的关键词只保存命中位置，关闭搜索即可释放结果缓冲。在 Windows 的 10,000 行回滚基准中，约 18 万个命中的结果缓冲从 30.4 MiB 降至 6.0 MiB。
- 主机列表支持逐项清除搜索词、协议和状态筛选。一键清除后保留当前分组和排序，焦点回到搜索框。
- 会话和全局传输列表都可用键盘查看失败原因、完整路径和续传断点。多台主机传输同名文件时，续传、重传和取消只影响选中的任务，长按按键只执行一次。
- 设置支持中英文跨分类搜索。选择结果可直接操作对应控件，取消搜索会回到原先的位置。
