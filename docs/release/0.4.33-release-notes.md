# Shellune 0.4.33

- 修复设置页无法上下滚动：在左侧导航点过某个分类后，滚轮和拖动滚动条都会被拉回该分类顶部，现在可以正常滚动。
- 标签栏变矮：窗口顶栏从 46 降到 38，标签高度从 34 降到 28，与旁边的紧凑按钮一致，终端可用高度更多。
- 首页重新设计：
  - 工具栏和主机列表限制在居中的内容宽度内，宽屏下名称、分组、时间与操作不再被拉散到屏幕两端。
  - 主机列表放在一张圆角面板上，面板高度随主机数量收缩；主机很少时不再是几行字飘在空白页面顶部。
  - 每行平时只显示分组、上次连接时间、收藏和“⋯”；鼠标指向、键盘选中或回车目标行时，编辑、复制、删除和“连接”按钮在原位置覆盖显示，不再有一整列“连接”文字，也不留空白占位。双击行或按回车仍可直接连接。
  - 主机少于 8 台时，列表下方显示“更多开始方式”：快速连接（在搜索框输入 user@host）、从 SSH 配置导入、本地终端、从备份恢复。
