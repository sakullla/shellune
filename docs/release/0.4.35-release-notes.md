# Shellune 0.4.35

- 密码库升级为首页侧边栏一级入口，与「设置 → 安全 → 密钥与密码」共享状态，并在启用设备锁时提供顶栏快捷锁控与命令面板动作。宽屏支持主从独立滚动浏览，支持按类型与未绑定筛选、搜索高亮、键盘导航、一键复制、文件导入密钥与编辑时随机生成密码；锁定态仅显示解锁卡片，不再展示误导性的空列表，离开密码库页面时自动隐藏已揭露的明文密码。
- 新建和编辑 SSH / RDP / VNC 连接弹窗新增密码库锁定感知、内联新建共享密码或导入/生成密钥自动绑定、缺失凭据告警及系统验证等待与就地重试反馈。
- 首页「最近」、最近连接快捷条、按上次连接排序、状态筛选与顶栏「+」启动器全面支持 SSH、RDP、VNC 与串口全协议；补齐首页与分组搜索高亮、搜索框到列表键盘闭环、单条「移动到分组…」、SSH「打开文件（SFTP）」与分组「新建子分组」等快捷操作。
- 改进多协议连接弹窗体验：取消勾选「记住密码」并点击「保存并连接」时当次直接使用临时密码拨号且用后不残留；RDP/VNC 地址栏支持粘贴 `user@host:port` 自动拆分回填；修正字段校验定位顺序并在修改输入时实时清除错误状态。
- 优化终端工作区与多窗格交互：专注模式隐藏常规底栏避免与退出浮标重叠；搜索栏支持二次快捷键重聚焦、全选/跳词/清空及「回到底部」新输出提示与避让；支持 `Ctrl/Cmd` 悬停高亮与点击打开 `http(s)://` 链接，右键菜单新增清空终端与回滚、代码片段与分屏操作；代码片段支持即搜即填自动归还焦点；补齐待连接标签菜单、SSH 复制会话留在终端工作区、分屏分隔条降噪、非活动分屏缩放、后台断线顶部横幅及全局浮层焦点隔离。
