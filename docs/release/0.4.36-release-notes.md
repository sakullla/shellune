# Shellune 0.4.36

- 服务器身份（主机指纹）变化时不再无路可走：连接卡片并排显示原指纹与现指纹（可点击复制），核实后可一键「移除旧指纹并重新核验」，随后像首次连接一样展示新指纹，由你明确接受或拒绝；跳板链中的任意一跳同样适用，绝不替你自动信任。
- 粘贴确认弹窗支持直接编辑：点击内容即可修改（Enter 换行，⌘↩ / Ctrl+Enter 粘贴，Esc 不粘贴），确认时写入修改后的文本；末尾带换行（粘贴即执行）时会明确提示并提供「去掉末尾换行」，行数不再把末尾换行算成一行；目标会话只显示一次。
- 终端现在会回答 OSC 10/11/12/4 颜色查询，报告实际显示的前景、背景与调色板颜色：omp、Neovim、Claude Code 等按终端背景选择主题的程序在浅色终端下不再画出黑底面板。
- 按 APCA 标准重新调校配色：浅色终端保持「黑深白浅」，白字黑底/黑字白底的提示符与状态栏不再糊成一片，亮黑（自动建议、注释）更安静；深色终端红/蓝/品红与亮黑达到 APCA 可读下限；深色界面的次要文字、说明文字、强调色、危险色与主按钮文字对比度提升；终端最低对比度修正改用 APCA。
- 顶部标签栏更清晰：「主机」固定标签不再在名称后显示数字（数量移至提示），与会话标签之间增加分隔，相邻的非当前标签之间显示淡分隔线。
- RDP / VNC 连接表单移除「新建密码…」按钮，直接填写密码或选择已保存的密码即可。
- 降低资源占用：本地终端空闲时不再每 12 毫秒轮询输出，改为有输出时唤醒；界面内 Logo 改用 256px 资源，不再常驻解码 1024px 图片。
