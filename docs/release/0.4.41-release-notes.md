# Shellune 0.4.41

- 终端支持 OSC 8 超链接：程序输出的链接在鼠标悬停时显示真实目标地址，按住 Ctrl（macOS 为 Cmd）点击即可打开。只打开网页（http / https）、邮件（mailto）和本机文件（file:///…），其他协议或指向其他计算机的文件链接会被拒绝并提示原因。
- 桌面通知：终端里的程序可以通过 OSC 9 / OSC 777 发出通知；命令运行超过设定时长（默认 10 秒）结束时也会提醒。只有终端不在前台时才通知，每个终端 10 秒内最多 3 条；系统无法显示通知时改为在标签上做标记。在 Linux 和 macOS 上点击通知会切换到对应终端。可在设置中开关并调整时长。
- 会话日志：本地、SSH 和串口终端都可以把输出记录到文件，支持纯文本和原始字节两种格式，记录期间标题栏显示标识。文件无法写入、文件或所在文件夹被删除或变为只读时，记录会停止并提示，终端本身不受影响。
- 终端内联显示 Sixel 图片（如 `img2sixel` 的输出）：图片绘制在所在单元格上，随内容滚动，打开 vim 等全屏程序后返回仍然保留。单张最大 4096×4096，每个终端最多 256 张、64 MB；损坏的图片数据不会吞掉后续输出。
