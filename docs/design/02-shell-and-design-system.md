# 应用外壳与设计系统

本文件是 `src/app/theme.rs`、`src/app/components.rs` 与 `src/app/view.rs` 的设计依据。
tokens 只在 `theme.rs` 定义一次，文档与代码不一致时以代码为准并同时修正本文件。

## 1. 结构：侧边栏 + 头部 + 对象区

四种对象（本地终端、主机、会话、传输）之间是平级切换，因此保留"单一侧边栏 + 单一对象区"；
终端打开后，对象区让位给终端，头部改为标签栏。整个窗口不再有底部状态栏。

```
+---------------+-------------------------------------------------+
| [>_] Shellune |  本地终端                         [+ 新建本地终端] |  列表页头部：标题 + 摘要/数量 + 主按钮
|               |  在本机上运行的 Shell                              |
| >_ 本地终端 ● 2|-------------------------------------------------|
| ▤  主机     3 |                 [>_]                            |  空的本地页 = 欢迎页：
| ≋  会话   ● 2 |             启动一个 Shell                       |  品牌图标、标题、简介
| ⇅  传输       |   [>_ Bash 默认] [>_ sh] [⌕ 自定义路径…]          |  Shell 磁贴（一键启动）
|               |   Ctrl+Shift+T 新建本地终端 · Ctrl+1-4 切换分区   |  快捷键提示
|               |               ▤ 连接到服务器                     |  去往主机页
|---------------|                                                 |
| ◎ 语言   中文 |                                                 |  侧边栏底部：语言、文字大小
| Aa 文字大小100%|                                                 |  活动摘要与版本
| ● 2 个会话 v0.1|                                                 |
+---------------+-------------------------------------------------+

终端页：
+---------------+-------------------------------------------------+
|  …侧边栏…     | (● Bash ×) (● SSH prod ×)       [+ 新建本地终端|v]|  头部即标签栏 + 拆分主按钮
|               | 本地 Bash  已连接            [文件] [重连] [× 关闭]|  会话栏（36px）
|               | PS C:\>                                          |  终端网格，铺满对象区
|               | 105×27                          ⧉ | A− 14px A+   |  终端状态行（28px）
+---------------+-------------------------------------------------+
```

- 空的本地终端页是欢迎页：Shell 磁贴横向排列，点击立即打开并记为默认；"连接到服务器"跳到主机页。
- 终端打开后，标签进入头部；主按钮与 Shell 菜单组成一个拆分按钮（左半新建默认 Shell，右半 ▾ 选择其他 Shell）。
  "自定义路径"在菜单内展开输入框，启动失败时输入框与菜单保留，便于修改路径。
- 在列表页（主机、传输等）仍有打开的会话时，标签以一条细标签条显示在头部下方，带 + 新建按钮。
- 会话页的主按钮也打开本地 Shell；传输页的主按钮在有可浏览的连接时打开其文件视图，否则转到主机页。
- 标签只显示状态点、远程标记（SSH）、名称和关闭按钮；非"已连接"时才写出状态文字。
  同名标签按打开顺序编号（"PowerShell 1"、"PowerShell 2"），完整的对象与状态在标签提示里。
- 程序名只在会话栏出现一次；终端状态行只放网格尺寸、复制与字号，进程结束后才重复程序名与结束方式。
- 列表页是最宽 880px 的居中阅读栏；终端铺满对象区，不加外框。
- 主机编辑表单为两列：名称 | 分组、地址 | 端口、用户 | 密钥文件，标签在字段上方。
- 原状态栏的内容移到侧边栏底部：语言切换（终端内切换语言的唯一途径）、文字大小、活动摘要、版本号。

- 标题栏（`view/titlebar.rs`）：Windows 与 macOS 隐藏系统标题栏，顶行（侧边栏头部 + 页头或标签栏）
  即标题栏。空白处是拖动区（Windows 走原生命中测试，双击最大化、贴靠布局照常；macOS 双击转交系统设置），
  标签与按钮不在拖动区内。Windows 在顶行右端画最小化 / 最大化或还原 / 关闭，关闭悬停为系统红；macOS
  红绿灯居中于 52pt 顶行，侧边栏头部为其留出 72pt。Linux 保留系统标题栏。
- 侧边栏可折叠为 56px 图标栏（按钮、Ctrl+Shift+B / ⌘B、命令面板）；折叠后名称与快捷键在提示里，
  有会话的分区以角标点表示。读音移到产品名的提示里。
- 新建 / 编辑主机是居中弹窗（`view/host_dialog.rs`）：名称 | 分组、地址 | 端口、用户；登录方式分段
  （密码 / 私钥 / 带口令私钥 / 系统 Agent）只显示该方式需要的字段；"记住密码 / 口令"把秘密存入系统凭据库
  （`shellune-storage::SystemSecrets`，keyring），主机文件只记一个标志；"连接后运行"在每次连接成功后
  键入远程 Shell 一次。底部为取消 / 保存主机 / 保存并连接，Esc 关闭，点遮罩不关闭（不丢失已填内容）。
  方式已选且所需信息齐全（已记住的秘密、私钥路径或 Agent）的主机一键连接；连接成功后直接切到其终端。
- 会话页从侧边栏或 Ctrl+3 进入时总是列表，选中标签才显示终端；会话行可打开、复制、重新打开、关闭、
  删除，右键与行尾"更多"给出同一菜单，列表顶部可一键清除已关闭的记录。

被否决的候选与理由见 `01-task-flows.md`；分屏仍按 R14 不做。

## 2. 视觉 tokens

颜色以 24 位 sRGB 常量给出，文字与状态色对四种表面的对比度由测试校验（WCAG AA：正文
4.5:1，图形 3:1）。

| token | 值 | 用途 |
| --- | --- | --- |
| canvas | `#0b0c10` | 对象区、终端背景（与 `shellune-terminal` 的 BACKGROUND 一致） |
| surface | `#101116` | 侧边栏、标签栏、卡片、列表行 |
| surface raised | `#16181e` | 选中的磁贴、菜单 |
| surface hover | `#1c1f27` | 指针悬停 |
| surface selected | `#23262f` | 选中的导航项、分段项 |
| border / border strong | `#1f222a` / `#2e323d` | 分隔线 / 控件边框与悬停边框 |
| text primary / secondary / muted | `#eceef3` / `#b3b8c6` / `#8b92a3` | 标题 / 正文 / 提示与计数 |
| accent / accent hover / on accent | `#8fa0ff` / `#a9b6ff` / `#0a0d22` | 主按钮填充、焦点环、选中图标 |
| brand end | `#b48cff` | 品牌渐变的第二个色标（accent hover → brand end） |
| accent tint / on tint | `#1e2340` / `#c9d0ff` | 次级强调（Soft 按钮、SSH 标记、徽标） |
| positive / warning / danger | `#5fd4a0` / `#f0c36d` / `#ff8c97` | 状态色，界面里只有它们是饱和色 |
| positive / warning / danger tint | `#12241d` / `#282114` / `#2b181d` | 状态 chip 与提示条的底色 |
| planned | `#a2a9ba` | 已关闭会话 |
| avatars | 6 组底色/文字 | 主机头像按名称取色，组内对比度由测试校验 |

浅色主题：上表是令牌（深色值），`theme::light::TABLE` 给出每个令牌的浅色值，`theme::swatch` 按当前外观取值，
因此视图只写令牌。主题可选跟随系统（默认）/ 浅色 / 深色（侧边栏底部"主题"、命令面板），跟随系统时监听
系统外观变化。终端默认前景、背景、光标与 16 个 ANSI 色另有浅色映射（`theme::light::TERMINAL`），程序
自设的 256 色与真彩色不变。浅色的正文、状态色、主色与终端色同样由对比度测试校验。

字号：caption 11、label 12、body 13、title 15、heading 17、hero 24；圆角 6 / 8 / 12 / 16；
间距 4 / 8 / 12 / 16 / 24。控件高度 32（紧凑 26），标签 32，导航项 34，头部 52，会话栏 36。
所有长度经 `Metrics` 按文字大小（90% / 100% / 115%）缩放。

图标是 `icons.rs` 里内嵌的 24 格线条 SVG（1.8 描边），由 GPUI 渲染为蒙版并取元素的文字颜色，
因此同一个图标适用于所有色调与悬停状态。

终端网格使用平台等宽字体（Windows Cascadia Mono、macOS Menlo、Linux DejaVu Sans Mono），
与测量单元格所用字体相同，保证列对齐与光标位置一致。

## 3. 状态语言

一个分区只能处于四种状态之一，映射集中在 `workspace::SectionState`：

| 状态 | 色调 | 呈现 |
| --- | --- | --- |
| 加载中 | warning | 居中状态卡片；头部标题旁有"加载中"chip |
| 失败 | danger | 居中状态卡片 + 原因 + 建议下一步；头部标题旁有"失败"chip |
| 空 | neutral | 居中状态卡片，以该分区的图标为徽记；下一步就是头部主按钮（本地终端页为欢迎页） |
| 有内容 | - | 行列表；头部摘要行写出数量（"2 个会话"） |

规则：

1. 只有"有内容"可以表现为成功；"已就绪"不再单独做 chip，数量即是结果。
2. 会话色调只由 `SessionState` 决定，`Connected` 是唯一 Positive；导航点只在其中有已连接会话时为绿色。
3. 提示、失败、确认问题都用同一个 `banner`：色调底色 + 左侧色条，文字保持主文字色。

## 4. 键盘、焦点与缩放

| 动作 | Windows / Linux | macOS |
| --- | --- | --- |
| 切换分区 | Ctrl+1...4 | Cmd+1...4 |
| 下一个 / 上一个分区 | Ctrl+Tab / Ctrl+Shift+Tab | Cmd+Tab / Cmd+Shift+Tab |
| 新建本地终端（终端内也有效） | Ctrl+Shift+T | Cmd+T |
| 文字大小 | Ctrl+= | Cmd+= |
| 界面语言（终端外） | Ctrl+L | Cmd+L |
| 关闭命令面板 / 菜单 / 提示条（终端外） | Esc | Esc |
| 命令面板（终端内也有效） | Ctrl+Shift+P | ⇧⌘P |
| 折叠 / 展开侧边栏（终端内也有效） | Ctrl+Shift+B | ⌘B |
| 关闭当前会话（终端内也有效） | Ctrl+Shift+W | ⌘W |
| 下一个 / 上一个标签（终端内也有效） | Ctrl+PgDn / Ctrl+PgUp | ⇧⌘] / ⇧⌘[ |
| 直达第 1-8 个标签 / 最后一个标签 | Alt+1-8 / Alt+9 | ⌃1-8 / ⌃9 |

终端内只占用 Shell 程序不读的组合键：Ctrl+W、Ctrl+P 分别是删词与上一条命令，因此只取它们的
Shift 形式。标签的中键单击关闭标签，右键打开标签菜单（复制标签、关闭、关闭其他、关闭右侧）；
批量关闭时有传输进行中的会话不会被静默关闭，而是像它自己的关闭按钮一样先询问。

### 输入框（`text_field.rs`）

单行输入框支持：点击定位、拖动选择、双击选词、三击全选；Shift+方向键 / Home / End 扩展选区，
Ctrl+←/→（macOS ⌥）按词移动，Ctrl+Backspace / Delete 按词删除；Ctrl/⌘ + A / C / X / V 全选、复制、
剪切、粘贴（Windows 另有 Ctrl+Insert / Shift+Insert / Shift+Delete）；右键菜单给出同样四项。粘贴的换行
变为空格。光标是绘制的细线，选区高亮（失焦时变淡），超长内容横向滚动并保持光标可见，获得焦点时显示
主色外环。密码框可点眼睛图标临时显示，且拒绝复制 / 剪切；路径框（私钥、SSH 配置、自定义 Shell、上传
文件、下载目录）右端有"浏览…"按钮，调用系统文件选择框。私钥路径中的 `~` 展开为用户主目录。

### 命令面板（`palette.rs` + `view/overlays.rs`）

参考 Tabby 的配置/连接选择器：一个快捷键打开、可输入过滤的统一入口。侧边栏顶部的"搜索…"框
与欢迎页的快捷键提示都指向它。未输入时按组列出：已打开的会话（带 Alt+N 提示与"当前"标记）、
可启动的 Shell、已保存主机（选中即打开连接表单）、四个分区、操作（关闭当前会话、新建主机、
导入 SSH 配置、切换语言、文字大小）。输入后按匹配度平铺排序：标题前缀 > 词首 > 标题包含 >
说明包含 > 三个字母起的按序模糊匹配；每个词都必须命中。↑↓/Tab 移动、Enter 执行、Esc 或点击
遮罩关闭，关闭后键盘回到原来的终端或页面。无匹配时显示"没有匹配的结果"，Enter 不做任何事。

侧边栏的会话数量只计未关闭的会话，与标签条一致；会话页的列表仍保留已关闭的记录。

终端内 Esc 与 Ctrl+L 属于终端程序；语言可点侧边栏底部的"语言"切换。焦点环为 accent 边框
（选中的导航项已有底色，不再叠加焦点环）。

## 5. 组件清单（`components.rs`）

| 组件 | 用途 |
| --- | --- |
| `button(label, Variant)` / `compact_button` | Primary（实心）、Soft（强调底色）、Secondary、Ghost、Danger 五级 |
| `icon_label_button` | 带图标的按钮（新建、连接、导入、文件、重连、关闭） |
| `icon_only_button` / `icon_button` | 只有图标（关闭、复制、新建标签）/ 短符号（A−、A+）的方形按钮 |
| `segmented` + `segment` | 主机视图、登录方式等互斥选择 |
| `card` / `card_title` / `field_row` | 表单与面板（主机编辑、导入、远程连接） |
| `banner` | 提示、失败、确认问题、操作结果 |
| `state_card` / `state_card_with_icon` | 加载中 / 失败 / 空，居中，带徽记 |
| `row` + `stacked` | 主机、会话、传输行（悬停高亮） |
| `chip` / `tag` / `badge` / `kind_badge` / `keycap` / `status_dot` | 状态、分组、数量、类型、快捷键 |
| `Tooltip` / `tooltip()` | 图标按钮、导航项与标签的悬停说明 |
| `icons::icon(Icon, size, color)` | 内嵌线条图标 |

新增分区必须复用同一组组件与 `SectionState`，不为某个分区单独发明状态表达。

## 6. 文案

- 产品名与两句简介由 `product.rs` 提供；简介按界面语言显示在空的本地终端页。
- 其余文案全部在 `copy.rs` 的双语表中；英文计数用 `copy::counted` 处理单复数。
