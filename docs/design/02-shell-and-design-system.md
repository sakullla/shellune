# 应用外壳与设计系统

本文件是 `src/app/theme.rs`、`src/app/components.rs` 与 `src/app/view.rs` 的设计依据。
tokens 只在 `theme.rs` 定义一次，文档与代码不一致时以代码为准并同时修正本文件。

## 1. 结构决定：一个导航栏 + 一个对象区

调研结论（详见 `01-task-flows.md`）：四种对象（本地终端、主机、会话、传输）之间是**平级
切换**，因此采用"单一导航栏 + 单一对象区"，而不是把主机栏、会话标签和文件面板同时摊开。

被否决的候选：

- **左主机栏 + 顶部会话标签 + 固定文件面板**：一次显示三类对象，密度高但需要一个默认选中项，
  且首次使用时四分之三的界面是空的；在 720×480 最小窗口下无法同时保证可读。
- **单窗口多面板（分屏）**：与 R14 的首版边界冲突，不采用。
- **命令面板优先**：发现性依赖用户先知道命令名，与 R12"入口可发现"相反；保留快捷键但不作为
  唯一入口。

保留下来的结构：

```
┌──────────────┬──────────────────────────────────────────────┐
│ Shellune     │ 当前对象 · 主机            [ 新建主机 ]      │  ← 头部：对象名 + 状态 + 主按钮
│ Shell-loon   ├──────────────────────────────────────────────┤
│              │                                              │
│ ▎● 本地终端 1│   分区内容：状态卡片 或 行列表                │  ← 对象区
│  ● 主机    2 │                                              │
│  ● 会话    3 │                                              │
│  ● 传输    4 │                                              │
│              │                                              │
│ Ctrl+1-4 …   │                                              │
│ 文字大小 100%│                                              │
├──────────────┴──────────────────────────────────────────────┤
│ Shellune 0.1.0 · 语言 English │ A modern terminal … │ 0 会话 │  ← 状态栏
└─────────────────────────────────────────────────────────────┘
```

多会话能力没有因为布局收敛而减少：会话分区承载全部会话，导航显示会话数量，切换会话不需要
改变导航结构。

## 3. 状态语言

一个分区只能处于五种状态之一，映射集中在 `workspace::SectionState`：

| 状态 | 色调 | 呈现 | 含义 |
| --- | --- | --- | --- |
| 当前版本未包含 | planned | 状态卡片 + 说明 | 能力尚未实现，**没有任何任务在运行** |
| 加载中 | warning | 状态卡片 | 请求在途，尚不知道结果 |
| 失败 | danger | 状态卡片 + 原因 + 建议下一步 | 上一次请求失败 |
| 空 | neutral | 状态卡片 + 下一步 | 真实结果为空 |
| 有内容 | accent | 行列表 + 计数 | 存在真实对象 |

规则（由测试固定，不由视图各自决定）：

1. 只有"有内容"可以表现为成功（`SectionState::is_success`）。
2. 计划中的能力点击主按钮后**不会**产生任何对象，只显示"没有启动任何任务"的提示。
3. 会话色调只由 `SessionState` 决定，`Connected` 是唯一 Positive；`TransferState` 中只有
   `Completed` 是 Positive。

## 4. 键盘、焦点与缩放

| 动作 | Windows / Linux | macOS | 说明 |
| --- | --- | --- | --- |
| 切换分区 | Ctrl+1…4 | ⌘1…4 | 与导航项上的提示一致 |
| 下一个 / 上一个分区 | Ctrl+Tab / Ctrl+Shift+Tab | ⌘Tab / ⌘⇧Tab | 循环 |
| 文字大小 | Ctrl+= | ⌘= | 90% → 100% → 115% 循环 |
| 界面语言 | Ctrl+L | ⌘L | English ↔ 中文 |
| 关闭提示条 | Esc | Esc | 仅在有提示时有效 |

- 焦点：窗口打开即把焦点交给外壳根节点，快捷键在首帧可用；每个导航项各有焦点句柄，选中
  与焦点同步，焦点环用 accent 边框表示，键盘与鼠标两条路径产生同一状态。
- 缩放：文字大小是用户的字体偏好，叠加在系统 DPI 之上；所有度量来自 `Metrics`，没有视图中
  的硬编码像素。缩放只改变大小，不隐藏内容——因此"放不下"永远不会被解释成"没有这个功能"。
- 平台习惯：快捷键标签随平台变化（`Platform`），Windows/Linux 显示 `Ctrl+1`，macOS 显示
  `⌘1`；不使用 macOS 上会被系统占用的组合。

## 6. 文案

- 产品名与两句简介固定为 `Shellune`、`连接远程，也专注本地。`、`A modern terminal for local
  shells, SSH, and SFTP.`（R18），由 `product.rs` 提供，界面只引用不复制。
- 其余文案全部在 `copy.rs` 的双语表中；缺失一个字段会同时让两种语言编译失败，避免只改一种
  语言。
- 中文不是英文的逐字翻译：例如"当前版本未包含"而不是"不在这个构建中"；测试要求两种语言都非
  空、中文必须含中文字符、且不出现与英文完全相同的条目。
