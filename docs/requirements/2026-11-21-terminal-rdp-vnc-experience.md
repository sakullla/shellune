# 需求：终端、SSH、RDP/VNC 与首页体验全面增强

日期：2026-11-21

## 一屏摘要

目标：在消除会话遮挡、定位负担、焦点困惑与状态跳变的基础上，系统提升首页与本地终端、SSH、RDP/VNC 的视觉质感、交互流畅度与使用效率，形成内容优先、控件可退、状态可恢复的统一体验。
使用者：在首页管理多协议主机与数百个分组，并在本地终端、SSH 终端与 RDP/VNC 会话之间高频切换的开发及运维用户。
范围：三类会话的内容区、工具控件、搜索与滚动、缩放、分屏、专注视图、全屏、键盘焦点与状态反馈（R1—R5），首页大规模分组导航与主机列表/筛选/连接动线（R9—R11），多协议新建/编辑表单（R12），以及跨页面视觉质感与高频控件一致性（R13）。
核心会话：提供跨会话统一且可恢复的专注视图与焦点边界（R1），让 RDP/VNC 工具栏低干扰自动退场且不阻断关键问题（R2），保障终端回看/搜索不打断（R3）、桌面缩放平移指针准确（R4）与单处一致的状态恢复（R5）。
首页与分组：分组可按名称或路径快速定位（R9），数百个分组下有界绘制并保持选择与阅读位置（R10）；主机列表支持按协议筛选、统一多协议行信息层级与已连接/直连/空态动线（R11）；多协议新建/编辑表单结构、分组选择与保存连接闭环保持一致顺畅（R12）。
视觉与一致性：在不脱离设计令牌与深浅主题对比度底线的前提下，统一首页与三类会话的视觉层级、留白节奏与终端搜索条等高频控件细节，避免无意义装饰与过度设计（R13）。
成功标准：在 1120×720 及更大窗口的规定主题、语言和会话布局中，主要控件可见或可恢复，无裁切、重叠及输入遮挡（R6）。
不做事项：不针对 720×480 适配或验收（R7）；放开首页主机列表与连接表单的 UI/UX 优化，但仍不扩展弱网或通用渲染性能指标（R10 除外）、不新增协议能力、不重构 SFTP 或底层协议栈、不改变认证/证书/凭据/剪贴板安全策略（R8）。
假设：本轮采用跨会话专注视图与桌面工具栏自动退场，视觉与控件精修继续遵循现有设计令牌与双语体系；具体快捷键、工具栏收起时机与协议筛选入口形态由后续方案确定，但不得破坏 R1—R5、R9—R13 的输入与可达边界。

## 完整需求

### R1 统一且可恢复的专注视图与键盘焦点

行为：本地终端、SSH 终端、RDP 和 VNC 均提供语义一致的专注视图。进入后隐藏非必要窗格标记和工具控件，让工作内容占据主要空间；退出后恢复进入前的会话布局和键盘焦点。三类会话使用一致的图标、术语、Esc 分层和关闭确认语义，但可采用适合各自内容的布局。具体专注视图入口键位可在后续方案中确定，不得占用 Shell 已使用的按键。

适用与失败边界：适用于 R6 规定的窗口基线内的单窗格、分屏和全屏。认证、证书、失败、重连和危险确认不属于可隐藏的非必要信息。隐藏后的控件不得截获输入；操作仍显示的控件时，输入不得穿透到 Shell 或远端桌面。终端原有 Esc、Ctrl+C、Ctrl+L 行为不得改变。

验收：

- 前置条件为分别打开本地终端、SSH 终端、RDP 和 VNC 会话，并使工作区持有键盘焦点；进入专注视图后，非必要控件消失，认证或失败等待处理的问题仍可见，工作区继续接收其应收到的输入。
- 在任一支持的会话中退出专注视图，进入前的窗格布局、活动会话和工作区焦点得到恢复，不新建会话、不拨号、不重复发送进入前的输入。
- 在专注视图中触发菜单、问题卡片或关闭确认，再按 Esc 逐层退出，按键只作用于当前最上层，不泄漏给背后的 Shell 或远端桌面。

### R2 低干扰的 RDP/VNC 工具栏

行为：RDP/VNC 工具栏保留手动收起和展开能力；当桌面画面持续接收输入且用户未使用工具栏时，工具栏自动退场。用户将指针移到工具栏所在区域或通过界面提供的键盘入口可将其恢复。具体自动收起时机由后续方案确定，不以高频闪烁或反复展开干扰远端操作。

适用与失败边界：只收起缩放、全屏等非关键工具；认证、证书、失败和重连提示必须保持可见。工具栏隐藏后，其原区域按远端画面处理；工具栏可见时，点击或按键不得穿透到远端。远端顶部和右上角的原生窗口控件不得因本机工具栏而不可达。

验收：

- 前置条件为 RDP 或 VNC 已显示画面且工具栏展开；持续操作远端而不使用工具栏后，工具栏收起，随后点击原工具栏覆盖的画面区域，远端按当前缩放收到对应指针位置，不存在残留命中区。
- 工具栏收起后，通过指针接近和键盘入口分别恢复工具栏；两种路径均不额外点击远端画面或发送远端按键。
- 工具栏收起期间出现证书确认或连接失败，对应问题与下一步立即可见，不要求用户先展开工具栏。
- 在远端窗口控制按钮所在区域执行点击，本机工具栏不遮挡该目标；点击本机工具栏自身时，远端不收到同一次点击。

### R3 连续的终端阅读、搜索与返回最新输出

行为：本地终端和 SSH 终端在持续输出时保留用户主动选择的阅读位置。用户回看历史、搜索、选择和复制时，新输出不得把视口拉回底部；界面提供可发现的返回最新输出入口。搜索关闭后恢复打开前的阅读位置和终端焦点。终端工具在三类会话的统一视觉语言下呈现，但不把本地搜索或选择变成远端程序的操作。

适用与失败边界：适用于主屏历史、单窗格和分屏。备用屏幕上的全屏程序以及程序接管鼠标的场景沿用终端既有语义，不强行为其添加历史搜索。搜索条持有键盘时，编辑键和粘贴只进入查询；焦点回到终端后，这些按键恢复 Shell 语义。

验收：

- 前置条件为终端持续产生输出且存在可回看的历史；向上滚动并进行一次拖选复制，视口保持在用户选择的锚点附近，所选文本与复制结果一致，新输出不造成意外跳转。
- 阅读历史期间触发返回最新输出入口，视口到达最新内容，后续输出恢复可见，且此次操作不向 Shell 写入命令。
- 打开搜索、逐处定位并关闭，视口恢复打开前的位置，键盘回到终端；搜索期间的 Enter、Esc、编辑和粘贴均不作为命令写入 Shell。
- 在分屏窗格中重复搜索和返回最新输出操作，只影响目标窗格，另一窗格的内容、滚动位置和焦点状态不被改写。

### R4 可预期的桌面缩放、平移、全屏与指针映射

行为：RDP/VNC 在适应窗口、100%、其他缩放级别、平移和全屏之间切换时保持明确的视图语义。切换全屏或调整窗口尺寸后，适应窗口模式重新适应可用区域，固定缩放模式保留其缩放级别；用户主动平移的内容不得被无关操作重置。绘制和输入使用同一坐标变换。

适用与失败边界：适用于 R6 规定的窗口基线。远端分辨率真实变化时可按当前模式重新布局，但不得把固定缩放悄悄改为其他模式。画面超出视口时只允许通过既有平移能力访问，不把裁切区域描述为完整可见。会话未显示画面或已断开时不接受远端指针输入。

验收：

- 前置条件为桌面包含已知坐标的可点击目标；分别在适应窗口、100%、放大并平移及全屏状态点击目标，远端收到的位置与目标一致，不发生比例偏移或平移偏移。
- 在适应窗口模式下调整窗口尺寸，画面重新适应新区域；在固定缩放模式下重复调整，缩放级别保持不变，视图不无故回到原点。
- 进入再退出全屏，返回进入前的窗口布局与所选缩放模式，标签、会话和窗格归属不变。
- 会话没有画面或已经断开时尝试点击，不向新会话或后台链路补发这些输入。

### R5 一致的状态反馈与安全恢复

行为：三类会话对连接中、重连中、断开和失败采用一致的反馈层级。同一事件只在一处陈述原因和下一步，不叠加状态卡、横幅和 Toast。RDP/VNC 重连期间保留最后画面并暂停输入；恢复后回到工作区，失败时提供可理解的原因和明确的下一步。关闭提示后，键盘返回之前的工作区。

适用与失败边界：没有历史内容的首次连接仍可使用状态卡片；已有内容后发生的状态变化不得遮住最后一屏或最后画面。不得静默自动重连，不得把脚本画面描述为真实连接成功，不得在错误详情中显示密码。证书与认证问题优先于普通通知。

验收：

- 前置条件为会话已有终端内容或桌面画面；模拟断开，用户能看到原因和下一步，最后一屏或最后画面仍可辨认，同一事件没有重复提示。
- 用户主动发起重连，在连接恢复前发送键盘和指针输入，这些输入不进入旧会话、不排队到新会话；取消或失败后仍可再次选择明确的下一步。
- 关闭或处理状态提示后，焦点回到对应终端或桌面画面；按一次后续按键只到达预期目标一次。
- 在凭据被拒绝的场景中检查界面和可复制诊断，密码及其明文片段均未出现。

### R6 1120×720 及更大窗口的显示与操作验收基线

行为：本轮以 1120×720 和 1680×940 为代表窗口尺寸，覆盖 100% 与 115% 文字、中英文、深浅主题，以及首页、单窗格、分屏、专注视图和全屏。主要控件必须直接可见或存在可发现、可操作的恢复入口，内容区与控件不得互相遮挡关键操作。

适用与失败边界：该基线适用于 R1—R5 及 R9—R13 的布局和交互验收，不要求所有维度做全笛卡尔组合，但每个维度都必须有实际证据。静态截图只能证明绘制状态，不能替代焦点、输入穿透、滚动和指针映射检查。小于 1120×720 的专门适配不属于本轮交付承诺。

验收：

- 在上述代表尺寸之间调整窗口并切换文字大小、语言和主题，主要控件没有裁切、重叠或不可恢复地移出窗口，当前内容和状态仍可辨认。
- 在首页、单窗格、分屏、专注视图和全屏中分别执行进入、操作和退出路径，所有主要动作均可到达，且不存在遮挡输入的不可见命中区域。
- 对每次视觉检查记录对应尺寸、文字大小、语言、主题和页面或会话形态；未执行的形态不得记为通过。

### R9 可按名称与路径快速定位的分组导航

行为：主机页分组区提供独立于主机查询的分组定位入口。用户可按分组名称或完整路径筛选；结果包含匹配分组及理解层级所需的祖先，不因主机名未命中而隐藏名称本身匹配的分组。重名叶子通过完整路径区分。用户可用指针或键盘选择结果，选择后打开该分组对应的主机列表，并使所选分组在分组区可见。无结果时提供清除查询的出口。

适用与失败边界：适用于包含数百个分组、多级路径和重名叶子的分组树。分组定位只改变导航与筛选，不创建、重命名、移动或删除分组，也不发起任何连接。清除定位查询不得清除主机页已有的搜索、状态筛选或排序；空结果不得被解释为没有保存任何分组。

验收：

- 前置条件为数百个分组中存在同名叶子和仅名称中含有查询词、其主机均不含查询词的分组；输入该查询词后，目标分组按完整路径出现，无需依赖主机命中。
- 在查询结果中只用键盘移动到目标并按确认键，右侧列表切换到该分组，目标行滚入可见区域，键盘焦点位置可被用户辨认。
- 输入没有任何分组匹配的文本，界面说明分组查询无结果并提供清除入口；清除后恢复原分组树，主机搜索、状态筛选和排序保持原值。
- 使用分组定位、清除查询及切换结果时，不产生连接请求，不改变任何分组或主机记录。

### R10 数百个分组下的有界绘制与状态保持

行为：分组区只实例化当前视口及固定预取范围内的分组行，实际绘制的界面行和焦点节点数量由视口容量决定，而不随分组总数线性增长。分组标题、定位入口、新建按钮、全部主机/收藏/最近连接及本地终端保持可达；分组列表独立滚动，键盘焦点移动时自动滚入可见区域。主机状态更新、主机搜索与筛选、窗口尺寸变化及分组编辑不得无关注销其他分支的展开状态或把阅读位置重置到顶部。

适用与失败边界：适用于 R6 的代表窗口尺寸和数百个分组的平铺或层级数据。虚拟化不得漏掉可经滚动或键盘到达的分组，不得改变分组计数及其与右侧主机列表的一致性。被重命名的分组沿用其新路径的选择状态；被删除或不再匹配查询的分组不得保留不可见焦点。R10 只规定有界绘制与交互连续性，不另设通用渲染耗时指标。

验收：

- 前置条件为固定视口中构造数百个分组；记录不同总分组数下实际实例化的分组行和焦点节点，数量只随可见范围及固定预取范围变化，不随总分组数增加。
- 将分组区滚动到中部并展开若干分支，随后更新某台主机的连接状态、修改主机搜索或调整窗口尺寸；未受影响分支保持展开，当前分组和滚动锚点不无故跳回顶部。
- 从分组区第一行只用键盘连续移动到初始视口之外的分组，焦点行依次滚入可见区域；按确认键打开的分组与焦点所示路径一致，没有跳过或重复。
- 滚动到分组区任意位置时，分组定位、新建、全部主机和本地终端仍可到达；任一分组显示的计数与打开它之后的主机列表结果一致。
- 重命名当前分组后，选择跟随新路径；删除当前分组或使其退出查询结果后，焦点转移到仍存在的可见目标，不停留在已删除或不可见的行上。

### R11 首页主机列表的信息层级、协议筛选与高效连接动线

行为：主机页提供清晰的多协议浏览与筛选体验。用户可在现有状态筛选与排序之外，按协议类型（全部 / SSH / RDP / VNC / 串口）快速筛选当前列表，且当前生效的筛选与排序以可一键清除的方式显式呈现。列表中的 SSH、RDP、VNC 与串口记录采用一致且克制的协议识别、元信息列对齐与状态表达，使名称、连接目标、协议类型、分组、最近使用/连接状态与行内操作主次分明。对已在本窗口打开会话的主机，界面提供清晰的状态信号与快捷操作；欢迎页、空分组、无匹配及搜索直连状态均明确说明当前状态与下一步。具体协议筛选入口形态由后续方案确定，不得增加工具栏拥挤或挤占搜索区。

适用与失败边界：适用于空主机簿、常规列表、大批量多协议混合列表及搜索直连场景。协议筛选与状态筛选、分组选择和关键字搜索组合生效且互相可见，清除筛选不得破坏用户的分组位置或触发连接。单击行内收藏、复选框、编辑、复制、删除或菜单图标不得误触发整行连接；未真正建立会话的记录不得显示已连接状态；非 SSH 记录不得被静默拉入仅支持 SSH 的批量命令任务。

验收：

- 前置条件为首页同时包含 SSH、RDP、VNC 与串口记录；切换不同协议筛选并与关键字搜索或状态筛选组合，列表仅显示符合全部条件的记录，计数与结果一致，一键清除后恢复原列表且不发起任何连接。
- 在多协议混合列表中检查各行布局，SSH、RDP、VNC 与串口行的协议标识、元信息列与行内动作对齐清晰，点击编辑、复制、收藏或删除图标不会误连主机。
- 当某台主机已在本窗口存在活动会话时，列表行清楚标示其已连接状态；在无匹配、空分组、空收藏或首次欢迎态下，页面明确给出原因与可直接执行的下一步动作。
- 进入多选模式后，可选中项与不支持批量命令的记录边界清晰，不出现视觉错位或把非 SSH 记录误纳入 SSH 批量任务。

### R12 一致且顺畅的多协议连接表单与分组选择体验

行为：新建与编辑主机/连接弹窗在 SSH、RDP、VNC 与串口之间保持一致的布局节奏、字段宽度比例与必填/可选分层，切换协议时窗口稳定不跳动。基础连接信息（地址、端口、凭据、名称与分组）与协议进阶选项主次分明，减少无谓滚动与视觉失衡。在包含大量分组的环境中，表单内的分组选择支持按名称或路径快速过滤与选取已有分组，也可直接输入新分组路径。表单保留「保存」与「保存并连接」的顺畅闭环，校验失败时在对应字段旁明示原因并定位，不丢失已填内容。

适用与失败边界：适用于新建与编辑 SSH、RDP、VNC、串口记录，以及数百个分组下的分组填写场景。编辑已有记录时不改变其协议类型；表单校验失败、取消或关闭弹窗不得污染已有记录，也不得泄露未保存密码或凭据到日志与提示中。「仅保存」不得自动拨号；「保存并连接」仅在校验与保存成功后发起一次连接尝试。

验收：

- 前置条件为打开新建弹窗并在 SSH、RDP、VNC 与串口之间切换；各协议表单的字段分组、端口等短字段比例和主次操作位置保持一致，无整窗闪烁或大幅跳动。
- 在包含数十至数百个分组的主机簿中打开新建/编辑弹窗，在分组字段输入关键字或路径片段可快速定位并选中目标分组，输入新路径后保存生效。
- 分别测试非法输入、仅保存与保存并连接路径：非法输入阻止保存并在对应字段显示原因且保留已填内容；仅保存返回列表可见新记录且不拨号；保存并连接保存后立即发起一次对应协议的连接。

### R13 跨页面的克制视觉质感与高频控件一致性

行为：在沿用设计令牌系统的前提下，统一首页、本地终端、SSH 与 RDP/VNC 页面的视觉质感、表面分层、边框与留白节奏。精修高频控件的视觉与交互细节，包括但不限于：终端搜索条的开关控件与窄窗排版（以清晰状态控件替代粗糙纯文本符号）、分屏多窗格下的活动窗格边界与归属表达、顶栏标签与底栏状态行的信息密度平衡，以及列表/菜单/弹窗的悬停、选中与焦点态一致性。所有优化以提升可读性、辨识度与操作效率为目的，避免无意义的装饰、过度阴影、高饱和视觉噪点与炫技动画。

适用与失败边界：适用于 R6 规定的窗口基线、深浅主题、中英文及 100%/115% 字号，同时兼容系统与应用的「减少动态效果」设置。不得在视图层引入绕过令牌系统的硬编码颜色，不得破坏深浅主题与终端色板的对比度守卫测试；开启减少动态效果时，所有状态、焦点与选中态仍可仅凭色彩、形状与文案独立辨认。

验收：

- 前置条件为分别在深色与浅色主题、中英文及 100%/115% 字号下打开首页、单窗格/分屏终端（含搜索条展开）、SSH 会话与 RDP/VNC 会话；各页面表面层次、边框、字体节奏与控件状态保持一致，无违和的粗糙占位控件或多余装饰。
- 在终端中展开搜索条并在常规与分屏宽度下切换大小写/正则选项，开关状态通过清晰的视觉控件与文本可读状态共同表达，且不发生按钮裁切或遮挡。
- 运行现有主题令牌与对比度守卫测试全部通过；开启减少动态效果后，选中、聚焦、加载与告警状态仍清晰可辨。

## 不做事项

### R7 不针对 720×480 适配或验收

本轮不为 720×480 新增布局、控件换行、分屏压缩或专项修复，也不将该尺寸的结果作为交付通过条件。不主动破坏该尺寸的现有行为，但仅在该尺寸发现的问题不构成本轮阻塞项。

验收：交付测试矩阵不包含 720×480 必过项；评审不以该尺寸的适配缺失否决 R1—R6、R9—R13 的交付。

### R8 不扩展性能目标、协议能力、SFTP/协议栈重构或安全策略

本轮不设立弱网或通用渲染性能指标，R10 的大规模分组有界绘制要求除外；不新增编码、多显示器、音频或更多外设重定向；不重构 SFTP 文件传输架构或底层 SSH/RDP/VNC/串口协议栈；不改变认证、证书、凭据保存和剪贴板安全策略。R11—R13 对首页主机列表、连接表单及跨页面 UI/UX 的优化与 R1—R6、R9—R10 所需的缺陷修复属于本轮范围，但不得借机突破上述协议、架构与安全边界。

验收：交付说明不包含未经另行授权的协议能力或性能承诺；SFTP 与协议栈核心行为以及认证、证书、凭据和剪贴板安全策略的既有边界不因本轮 UI/UX 调整而改变。
